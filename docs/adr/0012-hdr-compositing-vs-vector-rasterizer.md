# ADR-0012: HDR 映像合成とベクターラスタライザーを分離する

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

確認した Vello の `render_to_texture` は `Rgba8Unorm` を要求する。この経路に HDR の全画面合成を通すと精度と色域を失う。

## 決定

- 文字や単色形状は coverage マスクを生成し、RGBA16F 側で色を適用する構成を優先する。
- グラデーションや色付き SVG など coverage だけで再現できないものは、独自の GPU 描画パスで色処理を実装する。
- 同じベクター IR から異なるラスタライザーへ渡せるようにし、特定のラスタライザーを保存形式にしない。

## 影響

- ラスタライザーを差し替えられる。
- 色付きベクターの描画パスを自前で持つ実装コストが生じる。
