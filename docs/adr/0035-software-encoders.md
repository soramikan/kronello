# ADR-0035: ソフトウェアエンコードは AV1・ProRes・画像連番とする

- 状態: 採用
- 日付: 2026-10-02

## 背景

x264 / x265 は GPL のため同梱しない（ADR-0018）。OS のハードウェアエンコーダーがない環境（Linux の CI、GPU のないサーバー）でも書き出せる必要がある。H.264 / HEVC のソフトウェアエンコードには特許プールの論点がある。

## 決定

- ソフトウェアの配信用エンコードは AV1（SVT-AV1）とする。
- 中間・納品用は FFmpeg 内蔵の ProRes エンコーダーとする。
- 画像連番は常に書き出せる。
- H.264 / HEVC は、OS またはハードウェアのエンコーダーがある場合だけ提供する。ない場合は `ENCODER_UNAVAILABLE` を返し、代替を案内する。

## 影響

- GPL 部品と H.264 / HEVC ソフトウェアエンコーダーを配布せずに済む。
- ハードウェアエンコーダーのない環境では H.264 / HEVC で書き出せない。
- 同梱する FFmpeg に SVT-AV1 を含める必要がある（ADR-0036）。
- 音声コーデックの選定は AUDIO-000 で行う。
- 検討した代替案: OpenH264 の追加、ソフトウェアエンコードを提供しない。
