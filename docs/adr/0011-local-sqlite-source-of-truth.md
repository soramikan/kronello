# ADR-0011: 初期の正本はローカル SQLite とする

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

現在状態・イベント・revision を別々のファイルに書くと、途中の失敗で不整合が生じる。JSON ファイルを並行して書き換えると正本が二つになる。

## 決定

- 正本はローカルの SQLite とし、現在状態・イベント・逆操作情報・revision を同一トランザクションで更新する。
- JSON は不変スナップショットまたはインポート形式とし、第二の正本にしない。
- イベントだけを唯一の保存形式にせず、バージョン付き完全スナップショットも保持する。

## 影響

- 失敗した migration が元データを壊さないことを検証する必要がある。
- サーバー同期や共同編集は初期の対象外。
