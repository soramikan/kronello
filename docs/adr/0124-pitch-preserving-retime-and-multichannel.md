# ADR-0124: ピッチ保持音声リタイムとマルチチャンネル

- 状態: 採用
- 日付: 2026-10-08

## 背景

AUDIO-010 はピッチを保持する音声リタイムと 2ch 超の
マルチチャンネル入出力・ダウンミックスを要求する。
アルゴリズム・チャンネル表現・ミックス規則を決める。

## 決定

- ピッチ保持リタイムは `kronello-audio` の決定的 WSOLA
  （同期窓・固定探索範囲）で実装する。乱数・外部プロセス・
  プラットフォーム DSP を使わない。リタイム比は既存の
  有理数時間系から導出する。
- チャンネルレイアウトは `channel_mask`（版付き bitset、
  stereo/5.1/7.1/mono 等の標準配置）で表現する。position
  ベースの任意配置は扱わない。
- デコード・ミックス・エフェクト・エンコードの全段で
  channel_mask を保持する。2ch 超は bus にそのまま保持し、
  各音声エフェクトはチャンネルごとに適用する（LFE 除外規則は
  compressor/limiter のみ）。
- ダウンミックスは ITU 係数（center -3dB、surround -3dB、
  LFE 既定除外）の決定的係数表とし、出力 channel_mask に
  応じて明示変換する。暗黙の fold-down をしない。
- 非対応レイアウト・チャンネル数不一致は
  `UNSUPPORTED_CHANNEL_LAYOUT` の型付きエラーとする。
