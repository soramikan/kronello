# ADR-0028: 素材は相対パスと絶対パスの両方で参照し、hash で検証する

- 状態: 採用
- 日付: 2026-10-02

## 背景

素材はプロジェクト外に置く（ADR-0016）。プロジェクトと素材をフォルダごと移動する場合と、プロジェクトファイルだけを移動する場合の両方で参照が切れにくく、かつ別のファイルを黙って使わないことが必要。

## 決定

- Asset の locator は、プロジェクトファイルの場所を基準にした相対パスと、絶対パスの両方を持つ。
- 解決は相対パス、絶対パスの順に試し、見つかったファイルの content hash を照合する。
- 見つからなければ `ASSET_MISSING`、hash が一致しなければ `ASSET_HASH_MISMATCH` として報告する。別のファイルへ自動で差し替えない。
- `asset.relink` は、指定したフォルダから hash が一致するファイルを探してパスを更新する明示的な操作とする。内容の違うファイルへの差し替えは別の操作（`asset.replace`）とする。
- 受け渡しは `project.collect` で、プロジェクトの複製と素材を相対パスでまとめたフォルダとして書き出す。zip 化は利用者に任せる。

## 影響

- フォルダごとの移動では再リンクが不要になる。
- 絶対パスが作品ファイルに記録される。共有時にパスを含めたくない場合は `project.collect` の出力を使う。
- hash 照合の頻度と高速化（サイズ・更新時刻による省略など）は MEDIA-001 で設計する。
- 独自のアーカイブ形式を持たないため、zip 展開上限の論点は当面生じない。
