# ADR-0009: 式評価にネットワーク・ファイル・時計・非固定乱数を与えない

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

式が外部状態を読めると、同じ入力から同じ結果が得られず、キャッシュが成立せず、プロジェクトファイルを開くだけで任意の副作用が起こりうる。

## 決定

- 式は型付き AST と許可された組み込み関数で実装する。
- ネットワーク、ファイル、現在時刻、環境変数、非固定乱数、無制限ループ、動的ノード探索を与えない。
- 参照先・サンプル時刻数・ノード数・命令数に予算を設ける。
- 乱数は `random(seed, instance_id, element_id)` のように呼び出し順に依存しない形にする。

## 影響

- 式の依存を静的に列挙でき、循環を診断できる。
- 外部データを使いたい場合は、版を固定した DataAsset として取り込む必要がある。
