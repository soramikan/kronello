# ADR-0037: HDR は BT.2408 の基準白と Rec.2100 の PQ / HLG に従う

- 状態: 採用
- 日付: 2026-10-02

## 背景

作業用色空間は ADR-0024 で決めたが、HDR の基準白、出力の伝達特性、表示変換の扱いは未定だった。実装は M4（COLOR-001）だが、SDR 素材や色入力を HDR 作品へどの明るさで置くかは色の意味に関わるため、方針を先に固定する。

## 決定

- HDR の基準白は 203 cd/m²（ITU-R BT.2408）とする。
- HDR 出力は Rec.2100 の PQ と HLG に対応する。
- SDR の素材と色入力の白は、基準白に合わせて配置する。
- トーンマッピングと色域圧縮は、プレビューの表示変換と、明示的な SDR 変換出力でだけ行う。HDR 出力へは焼き込まない。
- 演算の詳細と検証は COLOR-001 で行う。

## 影響

- SDR 素材を HDR 作品に置いたときの明るさが一意に決まる。
- PQ と HLG の両方を検証対象とする必要がある。
- M0〜M3 は SDR のみを扱うため、この決定による実装は生じない。
- 検討した代替案: M4 まで保留、PQ のみに絞る。
