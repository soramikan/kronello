# ADR-0010: 未対応機能は保持できても最終出力は失敗させる

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

未対応の機能を無視してレンダーすると、利用者が気付かないまま画質低下や要素の欠落を含む成果物が出力される。

## 決定

- 未知・未対応の機能は保存時に失わない。
- 必要な機能が不足している場合、最終レンダーは `UNSUPPORTED_FEATURE` で拒否する。
- 式の失敗や資産の欠落も同様に、最終出力では基底値や代替表示へ黙って置換しない。プレビューの代替表示は警告付きにする。

## 影響

- 新しい版で作られたプロジェクトを古い版で開いても内容を失わない。
- `capabilities.get` と `project.validate` で、レンダー前に不足を検出できる。
