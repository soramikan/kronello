# ADR-0123: オプティカルフロー中間フレーム補間

- 状態: 採用
- 日付: 2026-10-08

## 背景

TRACK-003 は滑らかなスローモーションのための
オプティカルフロー中間フレーム補間を要求し、NLE-006 の
可変リタイムと組み合わせる必要がある。推定方法・
表現・失敗時の扱いを決める。

## 決定

- flow 推定は `kronello-tracking` に実装する決定的な
  ピラミッドブロックマッチ（前後方向の整合検査付き）とし、
  乱数・壁時計・外部プロセスを使わない。入力はデコード済み
  フレーム列、出力は版付き `FlowField`（格子ベクトル +
  信頼度マップ）。
- retime の `PiecewiseTimeMap` に `interpolation` モードを
  追加し、`"optical_flow"` が指定された区間では flow に
  基づく双方向ワープ合成で中間フレームを生成する。
  既定は従来のフレームサンプル補間で挙動を変えない。
- flow は必要なフレームペア間だけ遅延計算する。
  大域的な事前 bake は行わない。
- 信頼度が閾値を下回る領域が一定割合を超えた場合は
  `FLOW_CONFIDENCE_LOW` の型付きエラーとする。単純
  ブレンドへの黙った fallback は行わず、要求側が明示した
  `flow_fallback:"blend"` のときだけフォールバックする。
- GPU/CPU 参照の両経路で同じ数学を実装し、golden シーンを
  追加する場合は QA-004 の採用手順に従う。
