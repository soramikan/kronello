# ADR-0139: `kronello.audio.reverb` のフィードバックコム構成

- 状態: 採用
- 日付: 2026-10-09
- 置換対象: [ADR-0137](0137-remaining-standard-effects.md) の `kronello.audio.reverb` 「生成 IR の決定的畳み込み」条項のみ

## 背景

ADR-0137 は `kronello.audio.reverb` を「生成 IR の決定的畳み込み
（room 係数で IR をアルゴリズム生成）」と決めた。実装にあたり、
畳み込み型は次の点で FX-008 の要件と相性が悪いことが分かった。

- 畳み込みは IR 長に比例した遅延とバッファを要し、任意分割
  （partition）処理との境界整合を別途保証する必要がある。
- 生成 IR の係数列は依然として固定パラメータから導出する必要が
  あり、「IR を生成して畳み込む」と「フィードバック構造で直接
  残響を合成する」は決定性の観点で等価である。
- damp（高域減衰）を IR 生成側に入れると、wet/dry・decay と
  絡んだ正規化の検証が複雑になる。

## 決定

- ADR-0137 の `kronello.audio.reverb` に関する「生成 IR の
  決定的畳み込み」の実装方針を、本 ADR で部分的に置き換える。
  それ以外の FX-008 決定事項は ADR-0137 のまま変更しない。
- `kronello.audio.reverb` は決定的な並列フィードバックコム
  （FDN 系）として実装する:
  - チャンネルごとに 4 本のコム遅延線を並列に持つ。遅延長は
    48 kHz 基準で互いに素な固定長（1157/1361/1499/1723 サンプル）
    とし、全レンダーで同一の残響応答を共有する。
  - 各コムのフィードバック量は `decay_s`（RT60 相当）から
    `g = 10^(-3 D / T60)` で一意に導出し、`decay_s <= 0` は
    フィードバック 0 のタップドコムに退化する。
  - 各ループ内の一段ローパスが `damping` を実現する
    （0 = フラットループ、1 = 無音テール）。
  - wet タップはコム平均に揃え、`wet`/`dry` の出力レベルを
    単位整合させる。
- 外部 IR ファイルの取り込みは引き続き後続タスクとし、未対応の
  パラメータや将来の IR 参照は型付きエラーで拒否する
  （黙った近似をしない）。

## 根拠

- コム構成は状態変数がリングバッファと一段ローパスのみで、
  任意分割でもビット同一の系列を再現できる（決定性テストで
  検証済み）。
- 遅延長・フィードバック式は固定値と公開式だけで構成され、
  seed 付き擬似乱数や時計に依存しない。非固定乱数の禁止
  （式評価の不変条件）を満たす。
- RT60 換算式により `decay_s` の意味を文書化でき、テストが
  「減衰するテール」を解析的に検証できる。
