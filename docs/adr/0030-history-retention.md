# ADR-0030: 履歴は既定で全保持し、明示的な compact で切り詰める

- 状態: 採用
- 日付: 2026-10-02

## 背景

ADR-0026 により、イベントと逆操作情報を `.kronello` に永続化する。履歴は監査と Undo の根拠であり、黙って消えると困るが、際限なく増えるとファイルが肥大化する。

## 決定

- 履歴を自動では削除しない。
- `history.compact` は、指定した revision より前のイベントと逆操作情報を切り捨て、その時点の完全スナップショットを基点として残す。
- 切り捨てた範囲のイベントは Undo できない。
- 履歴が大きくなった場合は `project.validate` が警告する。

## 影響

- 履歴が消えるのは利用者が明示的に実行したときだけになる。
- 長期間使うプロジェクトではファイルが大きくなる。警告の閾値は STORE-001 で決める。
- 検討した代替案: 一定量への自動切り詰め、セッション終了時の逆操作情報の破棄。
