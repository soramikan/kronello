# ADR-0122: 手ブレ補正（スタビライズ）のモデルと変換生成

- 状態: 採用
- 日付: 2026-10-08

## 背景

TRACK-002 は TRACK-001 の `TrackingDataAsset` を用いた
手ブレ補正を要求する。トラッキング結果をどう安定化変換へ
落とし、クロップ・補間・境界処理をどうモデル化するかを
決める必要がある。

## 決定

- スタビライズは `TrackingDataAsset` を参照するクリップ
  エフェクト `kronello.stabilize` v1 とする。エフェクトの
  プロパティは既存の Property/animation 機構で保持し、
  ID を配列番号・表示名から導出しない。
- 平滑化は tracked point 群のフレームごとの推定運動を
  時間方向に窓平滑し、逆変換として各フレームの平行移動・
  回転・スケールを生成する。平滑窓・最大変位・最大回転・
  最大クロップ率はエフェクトパラメータとする。
- 境界処理は `border: fill | replicate | reflect` の
  版付き列挙とする。既定は `replicate` で、黒縁を既定値
  として出さない。`fill` は fill 色を別プロパティで指定する。
- 変換後にフレーム外を参照して埋められない領域が
  `max_crop` を超える場合は `STABILIZE_CROP_EXCEEDED`
  の型付きエラーとし、黒く欠けた最終出力を黙って返さない。
- 追跡データの欠落・全点喪失は `TRACKING_DATA_MISSING` /
  `TRACKING_INSUFFICIENT` の型付きエラーとする。
- 時間は正規化有理数の既存時刻系を使い、浮動小数点の
  時刻を保存しない。
