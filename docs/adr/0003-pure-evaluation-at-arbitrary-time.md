# ADR-0003: 通常アニメーションは任意時刻の純粋評価とする

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

前フレームの状態に依存する評価では、シーク・逆順レンダー・失敗後の再試行・分散レンダーで結果が変わりうる。

## 決定

- 通常のアニメーションは `value = f(snapshot, time, instance)` の純粋関数とする。
- 状態を要する表現（粒子等）は Simulation として専用ノードに分離し、固定刻みと checkpoint で扱う。
- 通常式からの再帰的な自己参照は禁止する。

## 影響

- 順序・逆順・ランダム順の評価が同じ意味的結果を返す（EVAL-001 で検証）。
- 値のキャッシュが時刻と入力のハッシュだけで決まる。
- 「前の値を積み上げる」表現は通常の式では書けない。
