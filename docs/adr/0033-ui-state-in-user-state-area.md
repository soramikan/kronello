# ADR-0033: GUI の UI 状態はユーザーごとの状態領域に保存する

- 状態: 採用
- 日付: 2026-10-02

## 背景

選択、pan / zoom、パネル配置、最後に開いていた Composition などは作品ではない（GUI-001）。保存先が `.cinewright` だと、見ただけでファイルが変わり、複数の GUI や利用者が上書きし合う。

## 決定

- UI 状態は、ジョブ記録と同じユーザーごとの状態領域に、プロジェクト ID で紐付けて保存する。
- `.cinewright` には UI 状態を書き込まない。

## 影響

- GUI で開いて眺めただけではプロジェクトファイルが変わらない。
- 別のマシンで開くと表示状態は初期値になる。
- プロジェクト ID は、ファイルの複製や移動をまたいで安定している必要がある。
