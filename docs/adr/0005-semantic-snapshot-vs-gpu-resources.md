# ADR-0005: 意味的スナップショットと GPU 資源を分離する

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

文書モデルが GPU テクスチャやデコーダーのフレームを保持すると、文書がバックエンド・GUI・GPU 資源の寿命に縛られ、ヘッドレス実行や device lost からの復旧が難しくなる。

## 決定

- 文書モデルと RenderSnapshot は意味的な値だけを持つ。
- 純粋モデル層は `wgpu::Texture`、`AVFrame` などを保持しない。値の評価と GPU コマンド発行を分ける。

## 影響

- 同じスナップショットを別のバックエンド・別のプロセスでレンダーできる。
- GPU 資源は render / gpu 層のプールとキャッシュで管理する。
