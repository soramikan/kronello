# ADR-0039: テスト素材は生成と CC0 / OFL に限り、小さいものだけ同梱する

- 状態: 採用
- 日付: 2026-10-02

## 背景

golden scene には映像・音声・フォントが必要だが、リポジトリは MIT OR Apache-2.0 で公開する予定であり、権利の不明な素材を含められない。大きなバイナリはリポジトリを肥大化させる。

## 決定

- 映像と音声は、可能な限りスクリプトで生成する（テストパターン、サイン波、VFR など）。
- 実写など生成できないものは CC0 または自作に限る。
- フォントは OFL のもの（Noto Sans JP、Noto Serif JP など）を版を固定して使う。
- 小さいファイルはリポジトリに含める。大きいファイルは、hash を固定した取得スクリプトで外部から取得する。
- 素材ごとの出典とライセンスを台帳に記録する。

## 影響

- リポジトリに含まれる素材の権利が明確になる。
- 大きい素材の取得元を維持する必要がある。取得できない場合、該当テストは失敗として扱い、黙って飛ばさない。
- サイズの閾値と取得元は QA-001 で決める。
- 検討した代替案: Git LFS、別リポジトリへの分離。
