# ADR-0041: 実装の優先順はコア契約、API、GUI の順とする

- 状態: 採用
- 日付: 2026-10-02

## 背景

GUI と自動化（CLI / MCP）は同格の入口とした。工数が足りず、どちらかを先送りする場面の判断基準がなかった。

## 決定

- 機能は、まずコアの契約として定義し、次に Command / Query API として完成させ（CLI / MCP で検証できる状態にする）、その上に GUI を載せる。
- GUI にしかない編集機能は作らない。
- 「同格」は到達点の性質であり、実装の順序ではない。

## 影響

- ロードマップ（M0〜M2 は GUI なし）と整合する。
- GUI の操作性の改善が、API の完成より後回しになることがある。
