# ADR-0121: ワークフロー UI（ショートカット・レイアウト・Undo 履歴）の永続化位置

- 状態: 採用
- 日付: 2026-10-08

## 背景

FLOW-001 はキーボードショートカットのカスタマイズ、
ワークスペースレイアウト保存、Undo 履歴パネルを要求する。
これらが作品ドキュメントの状態か、ユーザー環境の設定かを
決める必要がある。不変条件「入口専用の作品状態を作らない」
に沿った分離が必要である。

## 決定

- ショートカット割当・ワークスペースレイアウト・Undo 履歴
  パネルの表示設定は**作品状態ではなくユーザー環境設定**
  とし、`UserDefaults`（macOS の標準 defaults）に保存する。
  `.kronello` プロジェクトファイルには書き込まない。
- Undo 履歴パネルの内容は既存の `history.list` query を
  読み取り専用で表示する。選択的 Undo（`edit.undo` の
  `event_id` 指定）は既存 API をそのまま GUI に接続する。
- ショートカットはアクション名 → キー割当の辞書として
  保持し、未設定はデフォルトにフォールバックする。
- ワークスペースレイアウトは page ごとの panel 開閉・幅・
  分割位置などを保存し、作品の revision には影響しない。

## 影響

- 複数プロジェクト間でユーザー設定が共有され、作品ファイルを
  汚染しない。共有編集や CLI/MCP からは見えない。
- GUI のショートカット変更は即時反映され、再起動後も保持される。
