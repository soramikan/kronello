# ADR-0138: ワークスペース完成の範囲

- 状態: 採用
- 日付: 2026-10-08

## 背景

GUI-012 は残る UI 要素の統合と UX ポリッシュを要求する。M8 で
ワークフロー UI、M9 で二画面モニタ・メディアページ・書き出し
ページが揃った。残る要素の列挙方法と、作品状態/ユーザー環境/
一時状態の保存先の切り分けを決める。

## 決定

- 着手時に Computer Use で全画面を監査し、「service 層に実装済みだが
  GUI 未接続」「GUI 側のみ仮置き」「未実装」の3分類で残 UI 一覧を
  受け入れ記録に残す。
- ワークスペースレイアウト（パネル配置・モニタ割当・スコープ表示・
  表示倍率/解像度の既定）は個人環境の UI 状態として ADR-0033 の
  user-state 領域へ保存する。作品状態には含めない。
- M10 で完成させる優先 UI:
  - オーディオミキサーパネルの実装接続（トラック単位の
    volume/pan/mute と LUFS メーター）
  - マーカー一覧パネル（sequence/clip marker の編集・ナビゲーション）
  - 履歴パネル（イベントジャーナルの閲覧・undo/redo 位置表示）
  - 欠落素材 relink・欠落フォントのガイド付き dialog
  - 環境設定（ワークスペース既定・再生既定・スクラッチ位置）と
    キーボードショートカット一覧
  - service 未接続機能の棚卸しと接続（監査で検出したもの）
- 既存画面の操作感（フォーカス、空状態、エラー表示）は監査で
  見つけた個別問題を直す範囲に留め、大規模な再設計はしない。
