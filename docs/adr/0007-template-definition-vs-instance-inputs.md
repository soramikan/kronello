# ADR-0007: テンプレート定義とインスタンス入力を分離する

- 状態: 採用（v0.2 仕様から継承。実装による検証は未了）
- 日付: 2026-10-01

## 背景

テンプレートの配置ごとに定義を複製すると更新が伝わらず、逆に定義を直接書き換えると一箇所の変更が全配置を意図せず変えてしまう。

## 決定

- TemplateDefinition（版付き）と instance inputs を別に保存する。
- 共有定義を編集する操作と、公開入力を上書きする操作を別 API にする。
- テンプレート更新は版を固定し、移行計画とプレビュー比較を生成する。既存作品を自動更新しない。

## 影響

- 同じテンプレートの別インスタンスの入力が混ざらない。
- 公開していない内部 Property はバッチ操作で書き換えられない。
