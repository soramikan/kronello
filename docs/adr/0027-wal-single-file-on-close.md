# ADR-0027: 開いている間は WAL、閉じるときに単一ファイルへ戻す

- 状態: 採用
- 日付: 2026-10-02

## 背景

ADR-0016 でプロジェクトを単一の SQLite ファイルとし、ADR-0017 で複数プロセスからの同時編集を認めた。GUI が読みながらエージェントが書くには WAL が適するが、WAL は開いている間に付随ファイル（`-wal`、`-shm`）を作り、ネットワークファイルシステムやクラウド同期フォルダでは安全でない。

## 決定

- 通常は WAL モードで開く。
- 最後のプロセスが閉じるときに checkpoint し、付随ファイルを残さない。異常終了で残った場合は、次に開いたときに回復する。
- ネットワークファイルシステムやクラウド同期フォルダ上と判定した場合は警告を出し、安全モード（非 WAL、単一プロセスのみ）で開く。安全モード中に他のプロセスが開こうとすると `PROJECT_LOCKED` を返す。
- 開いている最中のファイルを直接コピーすることはサポートしない。複製には `project.export` などの API を使う。

## 影響

- ローカルディスク上では GUI とエージェントの同時利用が滑らかに動く。
- 同期フォルダ上ではエージェントとの同時編集ができない。
- 保存場所の判定方法と誤判定時の上書き手段を STORE-001 で設計する必要がある。
- 検討した代替案: 常にロールバックジャーナル、WAL 固定で安全でない場所では開くのを拒否。
