# ADR-0016: プロジェクトは単一の SQLite ファイル .cinewright とする

- 状態: 採用
- 日付: 2026-10-02

## 背景

ADR-0006 と ADR-0011 は保存の原則を定めたが、ファイルとしての形態は未定だった。

## 決定

- 1 プロジェクト = 1 つの SQLite ファイル `<name>.cinewright`。
- 素材はプロジェクト外に置き、locator と content hash で参照する。
- レンダーキャッシュは OS のキャッシュ領域に置く。
- 受け渡し用の素材同梱アーカイブは、別機能として書き出す。

## 影響

- ファイル 1 つを扱えばよく、OS や同期サービスをまたいでも扱いが単純。
- 素材の移動に対する再リンクの仕組みが必要になる（ADR-0028 で決定）。
- SQLite を WAL モードで開いている間は付随ファイルができるため、その扱いを決める必要がある（ADR-0027 で決定）。
- 検討した代替案: ディレクトリバンドル（`demo.cinewright/` 配下に DB・素材・キャッシュ）。
