# ADR-0040: 式の正本は AST とし、人間向けには小さな式言語を後から追加する

- 状態: 採用
- 日付: 2026-10-02

## 背景

式は型付き AST で実装する（ADR-0009）。GUI で人間が式を入力する手段が M3 で必要になる。After Effects 風の JavaScript は言語仕様が大きく、静的な依存列挙・予算・決定性と両立しにくい。

## 決定

- 式の正本は常に型付き AST とする。
- 人間向けには、中置演算と関数呼び出しだけの式言語を追加する。文、ループ、代入は持たない。
- 式言語と AST は一対一に往復できるものとする。
- JavaScript 互換にはしない。
- 構文の詳細は EXPR-001 の後に決める。

## 影響

- 式言語は AST の表示形式にすぎず、評価の意味は AST だけで決まる。
- 既存ツールの式をそのまま貼り付けることはできない。
- 構文の詳細は未決事項として残る。
