デザインシステムの値と規則を HTML で描いた見本。値はすべて tokens.json から生成した tokens.css を参照する。仕様と食い違うときは仕様の文書を正とする。t でテーマを切り替える。

色

強い色は 3 つの意味だけに使う: 琥珀 = 「今」とブランド、青 = 選択、赤 = 型付きエラー。種類の色はアイコンと細い下線だけ。左が Dark（既定）、右が Light。

トークンDarkLight用途

コントラスト

前景（行）と地（列）のコントラスト比を tokens.json の値から計算したもの。文字は 4.5:1、線と記号は 3:1 が基準（AA = 4.5 以上、3:1 = 3 以上、— = 3 未満）。line は装飾用で 3:1 未満でよい。

文字

UI は Noto Sans JP、数値とタイムコードは Noto Sans Mono（和文は Noto Sans JP にフォールバック）。時刻は浮動小数点で見せず、タイムコードか秒 + フレームで表す。
