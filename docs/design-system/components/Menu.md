# Menu

右クリックやメニューバー、PopupButton から開くコマンドの一覧で、項目ごとにアイコン・ショートカット・チェック・サブメニューを持てる。

## 利用側が渡すもの

- 項目: ラベル（動詞句）、任意のアイコン（Lucide）、ショートカット、種類（通常 / チェック / ラジオ / サブメニュー / 区切り / 見出し）、無効、破壊的操作か。
- 各項目の処理。1 項目の選択で Command を 1 回発行する。

## 見た目

- 地は `surface-200`、角丸 `radius-md`、影 `shadow-popover`、内側 `space-1`、最小幅 220px。
- 項目は高さ `control-height`、角丸 4px、4 列（アイコン 14px / ラベル / ショートカット / サブメニューの `chevron-right`）。ラベルは `body` の `ink`、アイコンとショートカットは `ink-muted`。
- hover とキーボードでの現在項目は `selection` の塗り + `on-selection` の文字・アイコン（macOS と同じ形）。
- チェック・ラジオの選択中は 1 列目に `check`。見出しは 10px 600 の `ink-muted`、区切りは 1px `line`。
- 無効は不透明度 0.45。破壊的操作（削除）は文字とアイコンを `danger` にし、最下段に区切って置く。

## 使い分け

- する: ショートカットは OS に合わせて表記する（macOS `⌘K`、Windows / Linux `Ctrl+K`）。キーの割り当ては全 OS で同じ。
- する: 続けてダイアログが開く項目は「…」で終える。
- しない: 1 つのメニューに 3 段以上のサブメニューを作らない。
