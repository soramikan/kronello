# Slider

範囲のある数値（音量、不透明度など）を大まかに合わせるスライダーで、正確な値の入力用に NumberField と組で置く。

## 利用側が渡すもの

- 最小・最大・刻み・単位、現在の値。
- `onPreview` と `onCommit`: ドラッグ中は候補表示、離した時点で Command を 1 回。

## 見た目

- 溝は高さ 4px、`line-strong`。値までの部分は `ink-muted`。つまみは 12px の `ink` の円に 2px の地色の縁。
- フォーカスはつまみの外側に `selection` の 2px リング。
- 右に NumberField（同じ値・単位）を置く。左のラベルは `label`。

## 使い分け

- する: 対数的に聞こえる量（音量の dB）は dB の値で直線に並べる。
- しない: スライダーだけで置かない（キーボードと正確な値の入力のため NumberField を必ず添える）。
- しない: 溝やつまみを琥珀・青で塗らない。
