# ToolStrip

Viewer で使う道具（選択・手のひら・ズーム・図形・ペン・テキスト、編集ページではブレード）を切り替える縦の列で、既定では Viewer の左端に付き、折りたたみと取り外し（移動）ができる。

## 利用側が渡すもの

- ページごとの道具の一覧（Lucide のアイコン、名前、ショートカット）と区切りの位置。
  - モーション: 選択 (V)・手のひら (H)・ズーム (Z) | 長方形 (M)・楕円 (E)・ペン (P)・テキスト (T)
  - 編集: 選択 (V)・ブレード (B)・手のひら (H)・ズーム (Z)
- 現在の道具と、切り替えの処理。道具の選択は UI 状態で、作品に書き込まない。
- 置き場所: `viewer-left`（既定）| `viewer-right` | `floating`（座標つき）、折りたたみの有無。

## 置き場所と保存

- 既定は Viewer の左端に付けた 40px の列（Viewer の stage の左、見出しと再生操作の間）。
- 上端の取っ手（`grip-horizontal`）をドラッグすると取り外して浮かせられ、Viewer の左端か右端に近づけると付く。
- その下のボタン（`chevrons-left`）で 14px の細い列に畳み、`chevrons-right` で戻す。浮かせた状態でも畳める。
- 置き場所・折りたたみ・浮動時の座標はワークスペースごとに覚える。ワークスペースを切り替えると、そのワークスペースで最後に使った状態に戻る。保存先はユーザーごとの状態領域で、`.kronello` には書き込まない。

## 見た目

- 付いた状態: `surface-100`、Viewer 側の 1px `line`、上下 `space-1`。道具は 28×28 の plain の icon ボタンに 16px のアイコン、区切りは 20px の 1px `line`。
- 浮いた状態: `surface-200`、角丸 `radius-md`、影 `shadow-popover`、内側 `space-1`。
- 現在の道具は `selection-bg` の塗りと `selection` のアイコン（「選ばれている」ものは青、という色の役割に従う）。hover は `control-hover`。
- 各ボタンはラジオとして振る舞い（`role="radio"`）、名前とショートカットをツールチップに出す。

## 使い分け

- する: 1 文字のショートカットは、テキスト入力中でないときだけ効かせる。
- しない: ツール列に道具以外のもの（スナップ・ガイド・表示倍率）を入れない。それらは Viewer の見出しか再生操作の行に置く。
