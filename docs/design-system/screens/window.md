# ウインドウの骨格

## 最小サイズ

- 13 インチのノート（MacBook Air 13 インチ、1470×956 pt 前後）で全パネルが実用的に収まることを最低条件とし、設計の基準を 1440×900 とする。
- 大きな画面では Viewer と下段を広げる。パネルの最小幅は各ページの値を下限とする。

## 縦の構成

```text
┌──────────────────────────────────────────────────────────────┐
│ ツールバー 44px                                               │
├──────────────────────────────────────────────────────────────┤
│ （状態の帯 32px: 安全モードなど、必要なときだけ）             │
├──────────────────────────────────────────────────────────────┤
│ ページの本体（四方型）                                        │
├──────────────────────────────────────────────────────────────┤
│ ステータスバー 24px（row-height）                             │
└──────────────────────────────────────────────────────────────┘
```

## ツールバー

高さ 44px、`surface-100`、下端 1px `line`。3 分割（左・中央・右）。

| 位置 | 内容 |
|---|---|
| 左 | macOS のウインドウボタン（OS が描く）、プロジェクト名（`heading`）、場所（`caption` の `ink-muted`） |
| 中央 | ページの切り替え（segmented、高さ 22px）: 編集 / モーション / テンプレート / 書き出し。⌘1〜⌘4（Windows / Linux は Ctrl） |
| 右 | 取り消す（`undo-2`）/ やり直す（`redo-2`）、区切り、ワークスペースの選択（PopupButton、`layout-panel-left` + 名前） |

- ツールバーに primary ボタンを置かない。書き出しは書き出しページの中で行う。
- 取り消す / やり直すは、この GUI セッションが発行した操作だけを対象にする（[10 デスクトップ GUI](../../architecture/10-desktop-gui.md)）。

## ページ

| ページ | 対象 | 文書 |
|---|---|---|
| 編集 | Sequence（カット編集） | [edit.md](edit.md) |
| モーション | Composition（アニメーション） | [motion.md](motion.md) |
| テンプレート | テンプレートの定義・variant・版 | [template.md](template.md) |
| 書き出し | 書き出し設定とジョブ | [export.md](export.md) |

- Sequence と Composition は別ページで扱う（ADR-0002 の別モデルに対応）。
- 編集ページで Composition クリップを開く（ダブルクリックか Inspector の「モーションで開く」）と、モーションページに移り、その Composition のタブを開く。
- 各ページは開いている対象をパネルのタブで持つ（モーションは Composition、編集は Sequence）。

## ワークスペース

- ワークスペースは、ページごとのパネル配置・大きさ・タブ・ToolStrip の置き場所と折りたたみ・Dope sheet の値の列の開閉をまとめた UI 状態。
- 既定のワークスペースは「標準」で、各ページの仕様の配置がそれにあたる。作業別のワークスペース（例: アニメーション重視、カット編集重視）は後から追加し、ツールバー右のワークスペースの選択で切り替える。
- ワークスペースを切り替えると、そのワークスペースで最後に使った状態に戻る。

## ステータスバー

[StatusBar](../components/StatusBar.md) に従う。左から保存状態と revision、直近の外部変更、未解決のエラー、右端にジョブの要約。

## テーマ

- Dark が既定で、システムの外観には追従しない。設定で Light に切り替える。
- どの画面も配置は共通で、トークンだけが切り替わる。
