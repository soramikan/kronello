# 書き出し

書き出し設定・書き出し前の確認・ジョブを扱うページ。形式とジョブの規則は [ADR-0035](../../adr/0035-software-encoders.md)、[ADR-0050](../../adr/0050-fixed-job-execution-and-publication.md)、[14 ジョブ](../../architecture/14-jobs.md) に従う。

## 配置

```text
┌────────────┬──────────────────────────┬────────────┐
│ 書き出し設定 │ プレビュー                 │ 書き出し前の │
│ 320px      │ （範囲の帯 + 再生操作）      │ 確認 304px  │
│            ├──────────────────────────┴────────────┤
│            │ ジョブ 232px                            │
└────────────┴───────────────────────────────────────┘
```

左列は下段まで通す。

## 書き出し設定（左）

- 対象（PopupButton: Sequence / Composition）、範囲（全体 / イン〜アウト）。
- プリセット: ProRes 422 HQ（MOV · PCM 24-bit）、AV1（MP4）、H.264（MP4 · VideoToolbox）、画像連番（PNG 16-bit + JSON · 音声なし）。H.264 / HEVC は OS のエンコーダーがあるときだけ選べ、その旨を行に添える。AV1・H.264・HEVC のプリセットは MEDIA-002 で追加する。
- 詳細: 解像度・フレームレート（対象に従う場合はその旨を添える）、色（SDR · Rec.709）、背景（MOV では明示が必要）、音声（PCM 24-bit · 48 kHz · stereo）。
- 出力先: パスの入力欄と「選択…」。
- 下端に「書き出す」（primary、全幅）と、「rev N の内容を固定し、別プロセスで書き出します。アプリを閉じても続きます。」の説明。書き出し前の確認にエラーがある間は押せない。

## プレビュー（中央）

- 見出しに対象名。Viewer の下に書き出す範囲の帯（範囲は `selection`、両端にタイムコード）と再生操作を置く。
- フレームは Viewer の領域の幅と高さの両方に収まる大きさで描く（縦長の領域でも横にはみ出さない）。

## 書き出し前の確認（右）

- エラーがあれば、上端に「エラーが N 件あります。解消するまで書き出せません。」の帯（`surface-200`、`triangle-alert` の `danger`）。
- 確認項目を 1 行ずつ並べる: エラー（コード・場所・解消する操作。例 `ASSET_MISSING` に「再リンク…」）、未対応機能の有無（`UNSUPPORTED_FEATURE`）、フォントの版の固定、音声のミックスとクリッピングで止まること。
- 見積もり: 尺（フレーム数）とサイズ。
- 見出しの右に「もう一度確認」（`refresh-cw`）。

## ジョブ（下）

- 見出し: 絞り込み（すべて / 実行中 / 完了 / 失敗）と「完了した記録を隠す」。
- 行は [JobRow](../components/JobRow.md)。状態・名前・形式と固定した revision・進捗または結果・操作（中止、取り消す、フォルダを開く、設定…）。
- 失敗は理由のコード（例 `ENCODER_UNAVAILABLE`）と次の操作を同じ行に出す。
