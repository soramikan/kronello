## 受け入れ対応

- 計画/適用の編集: `captions.import_plan` は cue 解析結果を `CaptionSet` + `ClipPlace`（必要なら `TrackAppend`）のコマンド列として `edit.plan` と同じ plan hash で提示し、`captions.import` は同一列を `edit.apply` で適用する。`cue_ids` は呼び出し側が払い出し、件数不一致は `INVALID_CAPTION_FORMAT` 相当の型付き拒否。`captions.export` は保存済み `CaptionDocument` を再直列化し、素材中の文字列を命令として解釈しない。
- 焼き付けと sidecar: `lower_sequence` は全 video track の後に caption track を降順せず最上位へ lowering し、`SceneContent::Caption` が `kronello-text` の locked font レイアウト、outline / background / bold・italic 合成を DAG へ渡す。`JobOutput::CaptionSidecar` は固定 snapshot から cue を直列化して staging 経由で原子的に publish し、`export_profiles` の discovery が `caption_sidecar` を列挙する。出力先の拡張子は `srt` / `vtt` / `itt` に限定される。
- 時間精度・文字化け・改行: SRT `,` / VTT `.` / ITT の clock・offset（`ms`・小数 `s`）時刻は正規化有理数 `Time` へ変換し、ms 精度を厳密に保持する。日本語 UTF-8・結合文字は grapheme 境界の span として保持される。`\r\n` / `\r` は `\n` へ正規化し、書き出しは `\n` で決定的。

## 保証範囲外

- ITT `ttp:frameRate` / `ttp:tickRate` の時刻基盤、region 配置写像、VTT の voice / region 設定、SRT/VTT の追加マークアップは `UNSUPPORTED_FEATURE` の型付き拒否であり実装しない。
- 実ファイルへの sidecar job 実行は worker プロセスを介する既存の job 機構に委ねており、本記録は submit 時検証と wire 形までを対象とする。GPU 画素の固定環境比較は対象外。
