# FX-007 アジャストメントクリップ（下位レイヤーへのエフェクト一括適用）の検証

現在の状態（2026-10-08）: M8 Lane D の作業ブランチ `m8-lane-d` で実装・検証を完了した。FX-004（ベジェマスク、[fx-004.md](fx-004.md)）の上に構築する。`docs/backlog/backlog.json` の状態更新はこの文書と同じコミットで行う。

## 契約

[ADR-0116](../adr/0116-adjustment-clips.md) に従い、`SourceRef` にペイロードなしの `Adjustment` バリアントを追加した。

- wire 表現は `{"kind":"adjustment"}` のみ。`SourceRef` の独自 Deserialize（フィールド一意性を要求する visitor）では `AdjustmentSource` の空 struct で `deny_unknown_fields` を検査し、余分な payload は拒否する。
- 意味: video track 上の adjustment clip は自身の `timeline_range` で、その時点までに合成された全下位 video track の composite をグループ化し、`clip.effects` を順に適用する。上位 track（および caption pass）は通常通りその上に合成を続ける。実装は scene IR に `SceneContent::Adjustment`（描画なしノード）を持ち込み、DAG 構築の root 走査で「それ以前の root = 下位 composite」を `apply_adjustment` が effect 適用済みノードへ書き換える。adjustment 同士の積み重ねはトラック順で逐次適用される。
- 制約（計画時に型付き拒否、`INVALID_CLIP` 系）: video track 以外への配置、`source_in != 0`、恒等でない `time_map`（Linear の非零 offset / 非 1 speed を含む一切の非線形マップを拒否。将来の hold 対応 piecewise も `matches!` の形状上拒否される）、`reverse_sampling`、`audio_retime != Reject`、`volume` 指定。`ClipTrim` / `ClipStretch` / `ClipSplit` は配置範囲のみの編集で、source window は mint しない（右片は恒等 time map・`source_in = 0` に再アンカー）。
- `clip.masks`（FX-004）は従来通り機能し、adjustment clip ではマスクカバレッジがエフェクト適用範囲を制限する（カバレッジ外は backdrop を保持、内側のみ effect 済み）。clip 非表示（所属 track の `visible = false`）ではノード自体が生成されず no-op となる。本ブランチのベースは lane A 統合前のため `Clip.enabled` は未導入で、統合後も同様に no-op となる設計（シーンノードが生成されない限り DAG 書き換えは発生しない）。
- `clip.opacity` は調整の強度として coverage と見なし、`strength < 1` は backdrop と effect 済みの lerp になる。範囲外の値は `RenderError::InvalidInput`。
- 音声プラン（`kronello-audio`）では video track 上の adjustment clip は audible でないため除外され、audio track への配置は sequence 検証で拒否される（audio 側でも防御的に unsupported を返す）。
- `SemanticVersions.adjustment_clip`（`ADJUSTMENT_VERSION = 1`）で snapshot 意味バージョンを固定し、adjustment 未使用の snapshot は旧バージョンと互換を保つ。
- 共有 API は既存の `clip_place` をそのまま使う（専用コマンドなし）。`SequenceQuery` の `ClipKind` に `adjustment` を追加した。GUI はエフェクトパネルの「アジャストメントクリップを追加」が `track_append` + `clip_place` の 1 Event で再生ヘッド位置の新規映像 track に配置し、Inspector は既存の `clip_set_effects` でその effects を編集する。
