# VEC-006 検証: テキストオンパスと文字単位アニメーター

状態: `m8-lane-g` 作業ツリーで実装・検証（2026-10-08）。対象は [ADR-0120](../adr/0120-text-on-path-and-character-animators.md)。

## 実装範囲

### テキストオンパス

- `TextDocument.path: Option<PropertyId>` を追加。`#[serde(default, skip_serializing_if)]` で旧文書と互換。参照 Property は `ValueType::Path` のみ許可し、`Value::Path` を解決する（model `vec006_path_property_requires_a_valid_path_value`）。
- 新規 descriptor は `0xf0000000_0010_46xx` 範囲: `path`（4600）・`character_scale`（4601）・`character_rotation`（4602）・`character_fill`（4603）・`character_follow_smoothing`（4604）。
- `kronello-vector::flatten_path`（tolerance 0.02 design_px）で guide path を折れ線化し、`PathMeasure` が subpath ごとの累積弧長テーブルを保持する。グリフは advance 中央を path 上の station に合わせ、baseline を接線方向へ回転する。`alignment` は path 弧長上の start / center / end に対応する。
- path 長を超えたグリフはエラーではなく drop し、`LayoutResult.dropped_on_path` に source range を記録する。`explain.node` の visibility に `TEXT_PATH_TRUNCATED`（Impact: Information、detail に `dropped_ranges`）を追加した。
- path + 縦書き、path + ruby、path + layout version 1 はすべて `UNSUPPORTED_FEATURE` の型付きエラー（`layout_path_line` 冒頭の検証、text test `vec006_path_rejects_vertical_ruby_and_layout_version_one`）。
- `kronello-render` の layout cache key に `text.path` を含め、path だけが異なる text の衝突を防ぐ。

### 文字単位アニメーター

- `CharacterAnimation` に `scale`（Vec2）・`rotation`（Angle）・`fill`（Color）・`mode`・`seed`・`follow_smoothing` を追加。いずれも serde default / option で旧文書を通す。
- `AnimatorMode`: `step`（既定・値をそのまま適用）・`ramp`（選択 unit の読み順で 0→1 補間）・`follow`（先頭 unit が最大、`follow_smoothing` で後方 unit を減衰）・`random`（(seed, unit source range) の splitmix64 finalizer で [0,1) の決定的 factor）。
- `apply_glyph_animation` はグリフ anchor を pivot に scale + rotation を適用し、offset は factor 乗算で平行移動、opacity は `1-(1-v)*factor` で alpha 乗算、fill は straight color へ factor 補間する。gradient グリフは実際に repaint が発生する場合のみ `UNSUPPORTED_FEATURE`（"character paint with gradient"）で拒否し、factor 0 の neutral 適用では失敗しない。
- `follow` mode で `follow_smoothing` が欠けている場合、[0,1] 範囲外の場合は型付き検証エラー（model `vec006_follow_requires_smoothing_and_unit_interval_range`）。
