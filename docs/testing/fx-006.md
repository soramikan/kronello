# FX-006 標準エフェクト拡張（glow / sharpen / vignette / corner pin）の検証

現在の状態（2026-10-08）: M8 Lane C の作業ブランチ `m8-lane-c` で実装・検証を完了した。検証環境は FX-005 と同一（Apple Silicon + Metal、rustc 1.95.0）。`docs/backlog/backlog.json` の FX-006 更新はこの文書の証拠に基づく。

## 契約

[ADR-0115](../adr/0115-keying-and-standard-effects.md) に従い、versioned effect `version = 1` として次の 4 種を実装した。

- `kronello.glow` — `threshold`(非負)・`radius`(design_px)・`intensity`(非負)。ストレート輝度が `threshold` を超える分を抽出し、sigma = `radius` の Gaussian でぼかして `intensity` 倍を元の画素へ加算する。半径の支持は既存の 3σ 規約。
- `kronello.sharpen` — `amount`(非負)・`radius`(design_px)。unsharp mask（`out = src + amount * (src - blur(src))`）。alpha も同じ式に従い 0..=1 に収める。
- `kronello.vignette` — `amount`(0..=1)・`midpoint`(0..=1)・`feather`(非負)・`roundness`(0..=1)。正規化された角距離に応じて RGB を暗くし、alpha を保存する。
- `kronello.corner_pin` — `top_left` / `top_right` / `bottom_right` / `bottom_left` の 4 つの Vec2（Composition design_px）。入力面の四隅を指定位置へ移す逆写像ワープ。destination quad が縮退・自己交差・非凸の場合は `resolve` / `validate` で型付き拒否する。入力の有無に依存せず常に検証する。

共通の規約は次の通り。

- すべて premultiplied working space で評価し、alpha の扱いを各 effect で明示する（vignette は alpha 保存、corner_pin はワープ先の alpha に従う）。
- glow / sharpen は `radius`（3σ）に応じて `halo` / `required_input` / `output_bounds` を拡張する。corner_pin は destination quad の凸包を output bounds とし、入力 source rect 全体を要求する。
- 非有限値・範囲外は `resolve` の型付き `EffectError`。corner pin の縮退 quad は `validate` で拒否する。
- kernel は `fx005006-keying-standard-f16-v1`（RGBA16F・binary16 RNE）。semantic version は 4 効果とも 1 で `SemanticVersions::current()` に登録する。

## 実行記録

FX-005 の実行記録と同一のコマンド群で検証した。

- `cargo test -p kronello-model --test fx005 --locked`: exit 0、6 passed。
- `cargo test -p kronello-render --test fx005 --locked`: exit 0、7 passed。

## golden シーン

`fx006-glow`（明暗 2 色・`threshold=0.5`・`radius=[1.6,0.9]`・`intensity=0.8`）、`fx006-sharpen`（LinearRec2020・`amount=1.5`・`radius=[1.1,0.8]`）、`fx006-vignette`（`amount=0.85`・`midpoint=0.2`・`feather=0.7`・`roundness=0.6`）、`fx006-corner-pin`（明示 source bounds の 4 隅ワープ）をカタログへ追加した。56 シーンの固定環境 baseline 更新は FX-005 の文書と同じ手順に従う。
