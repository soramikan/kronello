## 検出と修正

- 初回 direct check は Canvas の `some View` を `GraphicsContext.draw` に渡して型検査が失敗。Canvas の文字は token の font を持つ `Text` として描くよう修正。
- Viewer の Canvas 内関数で MainActor の model extent を参照し型検査が失敗。View で捕捉した extent を渡すよう修正。
- XCTest source の throwing / async 判定を nonthrowing autoclosure に渡した箇所を修正。
- 初回 key fixture は生成 UUID の大文字と共有 export の正規化小文字を比較して選択を解決できなかった。fixture の CurveId を正規化。
- 揃えるの検査は候補内の `CGFloat` 配列を `Double` として読めず、元の傾きで隣の接線を作っていた。候補の control 配列を明示 `Double` にして、保存後の傾きと Undo を再検査。
- GUI-001 review の `invalid type: map, expected f64` を Cubic 要求で再現。`arbitrary_precision` と adjacent tagged enum の payload buffering により、`value` が `kind` より前だと同じ値を拒否し、sorted JSON は成功した。GUI の `NativeProjectTransport` と test CLI helper は要求を常に sorted JSON で送る。共有 Rust decoder の任意フィールド順対応は未修正で、QA-002 / shared decoder の追跡事項。sorted request の成功を、任意順 decoder の修正と読み替えない。

## ホスト画面・操作の再現手順（Dark / Light、1440×900）

1. Shape を選択し、0 / 2 / 4秒の Position キーを確認する。Inspector と Dope sheet の名前・X/Y・単位・倍率が一致する。値列を畳む / 開くと216 / 376px、Inspector の設定行のラベルがずれない。
2. 一つの ruler handle と、レーン全体を貫く一本の amber playhead を確認する。レーン左右は space-2、先頭のキーが欠けず、末尾 tick はラベルなし。キーは未選択 ink-muted、選択 blue で、現在時刻のキーでも amber にしない。
3. キーをクリック、Shift、Command で選択する。空白を Shift-click しても追加しない。空白クリックは選択解除、空白から矩形ドラッグで複数レーンのキーを選択する。navigator diamond で current frame の追加 / 削除、前 / 次の矢印で正確なキー時刻へ移動する。
4. 選択キーを一つ / 複数でドラッグする。drag 中は候補だけ、release は status の revision が一つ進み、Undo 一回で全対象が戻る。左右矢印は1フレーム移動。magnet on / off、playhead / 他キーへのスナップ、非選択キーとの衝突の typed error を確認する。Inspector / CLI `project.export` でも同じ時刻を読む。
5. Linear / Cubic / Hold の形（diamond / circle / square）と実評価を確認する。Curve editor に切り替え、216px のチャンネル木、X / Y、実線と破線、eye、共通時間表示範囲・拡大率を見る。`scan` で全時間範囲へ戻す。選択キーの time·value label は blue、playhead 脇の各チャンネル値は amber。
6. 中央の Cubic キーで「揃える」を選び、片側のハンドルをドラッグする。release 時一つの Event、両側の傾きが揃い、Undo 一回で両方戻る。「分ける」では反対側が不変。Y に切り替えて編集しても X の時間イージングが変わり、常設 note が ink-muted で読める。未選択のハンドルは出さない。
7. Viewer に Position の青い1px軌跡と5px正方形を確認する。pan / zoom でも線と square の画面寸法を保つ。空間パスはドラッグで編集できない。Curve editor は時間グラフ。速度へ切り替えると「速度は表示のみ」、ハンドル / キー編集がなく、値は単位/秒。Expression Property を含む作品では「式のため編集不可」となり曲線なし。
8. キーを最後の一つまで削除し、同じ Event で Constant へ戻ることを CLI export / Inspector で確認する。現在の評価値が保たれ、再生・render query が空 Curve の評価エラーにならない。単独消費者は一回 Undo で Source とキーが戻る。共有 Curve の場合は編集した Property だけ Constant、他の Property / Expression の Source と Curve のキーは不変。Expression-consumer fixture でも評価が成功し、一回 Undo で元の Source が戻る。
9. drag 中に共有 CLI を使って外部変更する。古い候補を release すると `REVISION_CONFLICT`、既存 Viewer banner で「破棄」「もう一度適用」。外部変更した同じ Property に Undo すると `UNDO_CONFLICT` の sheet が出て部分的に戻らない。CLI と GUI の変更を同時に眺めても、他セッションの Event を session Undo で取り消さない。
