## 補足

- slip は `source_in` と内部 source mapping のみを動かし、`timeline_range` / `reverse_sampling` / piecewise `TimeMap` / audio retime policy を保存する（`slip_keeps_reverse_sampling_and_piecewise_maps_consistent`）。
- track の clip 配列は timeline start 順を正準形とするため、`clip_insert` / `clip_overwrite` は順序付き挿入で実装した（`nle.rs` の `insert_sorted`）。
- Undo は既存の ChangedKey 機構を共有し、各編集は `Structure(sequence_id, sequence_id)` と影響 clip の `Structure(clip_id, track_id)` を記録する。選択的 Undo の競合規則は NLE-002 時点のまま変更していない。
- transition を持つ範囲への overwrite は `TRANSITION_EDIT_CONFLICT` を要求する（明示的な transition 除去を先行させる）。
