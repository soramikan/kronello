## Dark / Light、1440×900 の実画面手順

1. Template page で Templates 264px、右列320px、下段196pxが所定位置に収まり、
   右列が下段まで通ることを両テーマで確認。base / portrait を横並びで比較する。
   下段の秒ルーラーは Authoring / 配置で同じ scale、intro / outro の保護区間は
   同じ秒数で同じ幅を保ち、mode と長さの文言が196px内に収まることを確認する。
   bounds segmented は選択が青で、一度取得した layout / ink / visual を切り替える。
   portrait に TEMPLATE_OVERFLOW と bounds unavailable、修正の導線があり、bounds を捏造しない。
2. 公開入力の DataTable の headline を編集する。比較だけは revision が進まない。
   「選択した配置の公開入力へ適用」を選ぶと Return / focus loss の重複でも一 Event。
   Undo 一回で値を戻す。Color、MediaSlot、数値、enum の欄、長い入力、IME を確認する。
3. 版タブで1.1.0を選び「移行計画…」。field / before / after と diagnostic を読める。
   Cancel では placement pin 不変、明示 Apply で一 Event、Undo 一回で旧 pin に戻る。
   外部 CLI 変更後の旧 plan は apply 不可。policy 下書きの公開だけでは既存 pin 不変。
4. hold / loop / stretch と最低中間尺の下書きを新版として公開し、明示 migration で配置を変える。
   配置 duration の変更とは独立であること、短すぎる duration では DURATION_TOO_SHORT を確認する。
5. Export page は設定320px、確認304px、下段232px、左列が下段まで通る。
   Composition / Sequence、範囲、閉 profile / version、音声、明示背景と出力先を選ぶ。
   H.264 / HEVC の登録なしは disabled と ENCODER_UNAVAILABLE、登録ありは device unverified。
   AAC は出さず、任意 codec / FFmpeg 欄がない。native Viewer は両辺に fit する。
   Viewer の play / seek は映像プレビューとして表示し、音声再生・A/V 同期は別の host 検証とする。
6. typed error fixture で code / 場所 / 理由と Start disabled。ready fixture で保存先を
   新しい `.mov` / `.mp4` または image-sequence directory にして再確認すると Start が有効。
   検査後に設定または作品を変更すると無効。チェック後に CLI を競合させ、
   expected_revision の REVISION_CONFLICT と「再確認」banner、worker 未起動を確認する。
7. 投入後 queued / running / percent / success を JobRow で確認し、fixed revision / hash が
   作品の後続編集で変わらない。Cancel は要求済み → canceled の確定を待つ。
   encoder unavailable の失敗は消えず code と「設定を確認」を表示する。
   GUI を閉じても worker が続き、再起動 / job list 更新で結果を取得できる。
8. gallery の7 component sheet と2 screen を両テーマで確認し、keyboard focus は各 control に一つだけ。
   blue は selection / focus、red は型付きエラーだけ、amber は現在時刻と
   supervisor が確認したページ一つの primary（Export の「書き出す」）の役割。
   VoiceOver、Return / Esc、メニューの disabled、長い名前・path・diagnostic を確認する。
