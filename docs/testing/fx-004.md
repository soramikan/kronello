# FX-004 ベジェマスク（クリップ適用・フェザー・拡張・時間変化）の検証

現在の状態（2026-10-08）: M8 Lane D の作業ブランチ `m8-lane-d` で実装・検証を完了した。`docs/backlog/backlog.json` の状態更新はこの文書と同じコミットで行う。

## 契約

[ADR-0114](../adr/0114-bezier-masks.md) に従い、クリップに `masks: Vec<Mask>` のベジェマスクスタックを実装した。

- `Mask` は `id: MaskId`（新規 stable ID 型）と `path` / `feather` / `expansion` / `opacity` の 4 つの `PropertyId` 参照、`mode: MaskMode`（`add | subtract | intersect | difference` の snake_case 閉集合）、`invert: bool`、`closed: bool` を持つ。各パラメータはクリップ所有の `Property` で、`kronello.mask.path`（`ValueType::Path`）など固定 UUID v4 の組み込み descriptor（`0xf0000000_0010_44xx` 系）を経由する。constant / curve / expression の既存評価をそのまま共有し、シーケンス時間で評価される。`ValueType::Path` は Hold 補間のみ対応するため、パスの時間変化はキーフレームの段階的切替として表現される。
- 評価はクリップのラスタライズ後・clip effects の前に、マスクカバレッジをアルファ乗算する。ラスタライズは `kronello-vector` のフラット化を再利用し、`expansion` は頂点法線オフセット（`offset_path`、miter limit 付き）、`feather` はカバレッジのガウスぼかし、`invert` は反転、`opacity` はカバレッジ乗算として DAG 上に構成する。スタックの結合は authored 順で、先頭 `subtract` は従来通り全カバレッジからの反転として扱う。
- 予算は型付きで拒否する: マスク数 64/clip（`MASK_BUDGET_EXCEEDED`）、パス点数 1024/path・合計 8192/clip、ID 重複は `MASK_DUPLICATE_ID`、参照・descriptor 不一致は `MASK_INVALID_PROPERTY`、評価値の範囲外（負の feather、0..=1 外の opacity）は `MASK_OUT_OF_RANGE`。パストポロジ不正は `MASK_INVALID_PATH`。
- 共有 API は `clip_masks_set { sequence, clip, masks, properties }`（`TimelineCommand::ClipMasksSet`）で、マスクスタックと参照先プロパティを原子置換する。`clip_set_effects` と同じ plan/apply/undo/冪等の枠組み。`ClipSplit` は右片へ新しい `MaskId` と remap 済み `PropertyId` を割り当てる。
- マスクは video track のクリップのみ有効で、audio/caption track 上の `masks` は `Sequence::validate` / `clip_masks_set` の双方で型付き拒否する。
- `SemanticVersions.clip_mask`（`MASK_VERSION = 1`）で snapshot 意味バージョンを固定し、マスク未使用の snapshot は旧 semantic version と互換を保つ。
- GUI: クリップ Inspector にマスク一覧（追加・削除・モード・フェザー・拡張・不透明度・反転・閉合）を `clip_masks_set` 経由で接続し、Edit ページのビューアには選択クリップのマスク輪郭とベジェハンドルをドラッグ可能な専用オーバーレイとして実装した。アニメーション付きパラメータは読み取り専用で固定化しない。
