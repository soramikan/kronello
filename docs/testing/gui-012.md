## 実装内容

- 音声パン: `kronello.audio.pan` 組み込みディスクリプタ、`Clip.pan`、
  `validate_pan`（定数ソース・[-1,1] の境界）、timeline コマンド
  `clip_set_pan` を追加した。基本音声プランは `UNSUPPORTED_FEATURE` で
  型付き拒否し、v2 ミキサーはクリップゲイン・フェード後に等パワー則の
  パンゲインを掛ける（crates/kronello-model/src/builtin.rs、
  sequence.rs、crates/kronello-audio/src/document.rs、advanced.rs、
  crates/kronello-service/src/edit.rs）。
- `audio.loudness` の入力に `track` を追加し、トラック単位の
  BS.1770 計測を可能にした（crates/kronello-service/src/loudness.rs）。
- AppModel: トラックパン操作 `setTrackPan` / `trackPan`、トラック/シーケンス
  ラウドネス計測、`audio.normalize` 呼出し、`clip_set_pan` 発行
  （AudioMetering.swift・ClipAuthoring.swift）。`CaptionImport.swift` に
  `captions.import_plan` + `captions.import` の導線を実装し、返却 Event を
  セッション undo に記録する。`JobActions.swift` に `job.list` /
  `job.cancel` / `job.resume` / `job.prune` と `asset.relink` のガイドを
  実装。`MediaPageModel.swift` に `proxy.status` / `proxy.generate` /
  `proxy.clear` / `project.collect` を実装。
- user-state 分離（ADR-0033）: `WorkspaceState.mixerVisible` /
  `scopesVisible`、`EditViewSettings.editScale` / `editSnap` /
  `sourceTrack`、`AppPreferences.playbackScrub` / `playbackMuted` /
  `playbackLooping` / `scratchDirectory`、`UIStateStore.hasState` を追加。
  `KRONELLO_RASTER_CACHE_ROOT` は `NativeProjectTransport` 生成前に
  AppController が適用する。
- UI: ミキサーにパンつまみと LUFS 表示・計測ボタン、プロジェクト
  パネルに「マーカー」タブ、インスペクタにマーカーコメント編集と
  -23 LUFS 正規化ボタン、素材欠落クリップに再リンクガイド、
  FONT_MISSING ダイアログにフォント登録ガイド（共有 `font.pin`、
  `ui.fontSources` に保存・フォント置換はしない）、Jobs シートの
  行ベース化（キャンセル・再開・出力表示・整理）、履歴パネルの
  現在位置表示、設定タブ（一般・再生・ワークスペース・ショートカット）
  とキャッシュフォルダ選択を追加。

## 見送り・既知の制約

- トラック音量/パンは「そのトラックの全クリップへ同じ値を書く」方式を
  踏襲する（`clip.volume` と同じくトラック段ゲインのモデルフィールドは
  存在しないため）。クリップ単位の値は個別に維持される。
- `audio.loudness` はベースリビジョン固定の計測クエリであり、連続
  メーターではない。ライブ表示は従来どおり peak/RMS を使う。
