# IO-001 外部モニタ出力: SDI/NDI 等のリファレンス出力

[ADR-0134](../adr/0134-external-monitor-output.md) の実装範囲:
`OutputDevice` 契約（kind / format / colorspace / pacing / typed error）、
`io.output.*` 共有操作、ref monitor（外部 display の全画面 CAMetalLayer）、
Syphon runtime 検出 + Metal texture publish、SDI/NDI/deck 制御の vendor SDK
アダプター境界（この build では検出のみ・常に型付き拒否）。

## 再現手順

```text
cargo test -p kronello-service --test io001 --locked
cargo test -p kronello-ffi --test output --locked

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build --package-path apps/macos
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --package-path apps/macos
```

## 実行証拠（2026-10-08 macOS host, Apple Silicon / Metal）

- `cargo test -p kronello-service --test io001`: 4 tests pass。
  - `io.output.list` が ref_monitor / syphon / sdi / ndi の 4 件を
    detected / available / active / transport / detail 付きで返す。
  - headless transport の `io.output.enable` / `io.output.disable` は
    全 kind で `UNSUPPORTED_FEATURE`。
  - `vendor_output_open` は SDK 名と検出結果を含む `UNSUPPORTED_FEATURE`。
  - Request / ResultData の wire codec roundtrip。未知 kind はデコード拒否。
- `cargo test -p kronello-ffi --test output`: 3 tests pass。
  - FFI worker 越しの `io.output.list` は同じ 4 件を返す。
  - `io.output.enable(sdi|ndi)` は `UNSUPPORTED_FEATURE`。
  - `io.output.enable(ref_monitor)` は surface 未 attach で `SURFACE_UNAVAILABLE`。
  - `io.output.enable(syphon)` は framework 未検出時 `UNSUPPORTED_FEATURE`、
    検出時は program surface 未 attach の `SURFACE_UNAVAILABLE`。
  - `kronello_surface_attach_at(slot=8)` は program surface 未 attach で
    `SURFACE_UNAVAILABLE`。
  - `io.output.disable` は未 active な kind でも `active:false` の型付き応答。
- `cargo test -p kronello-ffi --lib output::tests`: 2 tests pass（GPU あり環境）。
  - `external_output_blit_matches_program_transform`: 既知の線形
    premultiplied Rec.709 画素を `Blit` で BGRA8 target へ描き readback、
    CPU で計算した program monitor と同じ SDR sRGB encode と一致
    （±1 u8、alpha は常に opaque）。これは Syphon publish texture 経路と
    同一の 1:1 crop transform であり、外部出力が program monitor と同じ
    変換結果になることを示す。
  - `external_output_scaled_blit_encodes_uniform_frame`: 一様色 4x4 を
    scale=2 で 2x2 target へ scaled pipeline で描き、同じ encode と一致。
    ref monitor が異なる surface サイズでも同じ変換を使うことを示す。
- `cargo test -p kronello-framebridge --test output`: 3 tests pass。
  - detection probe（syphon / DeckLink / NDI）は `dlopen` のみで panic しない。
  - `SyphonServer::create` は framework 未検出時 `UnsupportedFeature` の型付き拒否。
  - `publish_texture` は native BGRA8 MTLTexture と wgpu HAL handle の対を作り、
    0・上限超過の寸法は型付き拒否。

## 検証できたこと

- 全出力が `OutputDevice` 契約を通り、activation は `io.output.enable` の明示要求のみ。
- 検出は runtime `dlopen` のみ。framework / SDK / display 不在は型付き拒否で、
  黙った no-op も別出力への暗黙 fallback もない（テストで確認）。
- 外部出力は program redraw の同一 `FrameSource` を同一 `Blit` 変換で present し、
  BGRA8 target の readback が program monitor の変換結果と意味一致する
  （GPU 環境での parity 検証済み）。
- `io.output.*` は共有レジストリ経由で CLI / MCP / FFI に同じ schema で露出する
  （`kronello io output list` で 4 件の enumeration を確認）。
- 既存 preview 経路は既定で変わらない（`preview.outputs` は出力が有効な時だけ付く）。

## 実機で残る手動確認項目

- 外部 display 実機: `NSScreen != main` の全画面 window、
  `NSScreen.colorSpace` が CAMetalLayer に適用されること、全画面表示の動作。
- backing scale 変更時の drawable size / surface resize。
- Syphon 実機: `Syphon.framework` 導入環境での受信側 roundtrip
  （Syphon Simple Client 等で publish される frame を確認）。
- SDI / NDI / deck 制御: vendor SDK 配布物と実機がある環境での adapter 実装・検証
  （この build は境界定義のみで常に `UNSUPPORTED_FEATURE`）。
- 複数 display / 色域の異なる外部モニタでの視覚的確認。
