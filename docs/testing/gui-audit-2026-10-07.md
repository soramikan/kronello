# macOS GUI 総点検 — 監査・修正記録（2026-10-07）

状態: `main`（M7 マージ後）のネイティブ GUI を open-computer-use で実機点検し、確認できた欠陥は同セッションで修正した。本記録は修正点・検証結果・未接続機能の棚卸しを残す。

## 点検した範囲

open-computer-use（アクセシビリティツリー＋スクリーンショット）で以下を実機操作した。

- Welcome 画面: 新規 / 開く / 最近のプロジェクト一覧 / 起動時表示トグル
- モーションページ: レイヤー一覧・選択・Inspector・dope sheet・キーフレーム・式・カラー編集・Matte・テキストレイヤー・レイヤー削除
- 編集ページ: 素材一覧・シーケンスタブ・編集ツール・トランスポート・In/Out・マーカー・スナップ・トラック表示/ミュート・ロック・クリップ Inspector（時間・速度・逆再生・音量・不透明度・描画モード・Effects・カラー・字幕・波形）
- テンプレートページ: 空状態の表示
- 書き出しページ: 対象/範囲/プリセット選択・プリセット全種・字幕形式・HDR・出力先・意味的検査・ジョブ投入・進捗・完了・中止・フィルタ・Finder 表示
- ステータスバー: 保存状態・再生状態・revision・ジョブ進捗
- revision 競合 / undo 競合のダイアログ

## 確認・修正した問題

| 問題 | 原因と修正 | 実機確認 |
|---|---|---|
| トラック表示・ミュートボタンが常時無効 | `EditPage.swift` の `visibilityEnabled` が `pendingCandidate != nil` のときだけ有効という反転条件。`EditorModel.submit` は candidate 保留中を拒否するため実質到達不能だった。`pendingCandidate == nil` に修正 | 有効化を確認。V1 非表示→プレビュー変化・rev 前進・イベント記録。A1 ミュートも有効 |
| 「トラックの表示・ミュートは未対応です」の誤ヘルプ | 機能は実装済みなのに未対応と表示。`Track.swift` を「ロック中または実行中は切り替えられません」に修正 | 無効時のヘルプ文面を確認 |
| `PropertyFields.swift` の死コード `swatch(_:)` | 「色の編集は後続タスクです」の stale コメント付き未使用関数。`PropertyColorEditor` で実装済みのため除去 | ビルド確認 |
| 描画モードが 20 種中 3 種のみ | Inspector が Normal/Multiply/Screen のみ列挙。`EditPresentation.blendModes` に全 20 種を定義し接続 | ポップアップで 20 種を確認、Multiply 選択で rev 前進・イベント記録 |
| 音声クリップ音量が GUI 未接続 | `clip_set_volume` は実装済みだが UI なし。`setClipVolume` / `clipVolume` を `ClipAuthoring` に追加し音量セクションを Inspector に接続 | 音量セクション表示、99% 変更で `kronello.audio.volume` が rev 5 の constant property として記録 |
| `av1_webm` が必ず失敗 | `ExportPageModel` が `audio_codec: "alac"` 固定で、WebM が要求する Opus と不一致。プロファイルの `audio_codecs` から選択（ALAC 優先・なければ先頭）に修正 | プリセット一覧に 9 種表示。WebM Opus 表記を確認 |
| 字幕サイドカー書き出しが GUI 未接続 | プロファイルはあるが形式選択・対象制約・拡張子の UI がなかった。SRT/VTT/ITT 選択、sequence 限定バリデーション、拡張子追従を追加 | composition 対象で `UNSUPPORTED_FEATURE`、sequence 対象で検査パス、`.srt` ジョブ投入・完了（当該シーケンスに字幕なしのため 0 バイト出力は正常） |
| Gaussian Blur / Drop Shadow が挿入のみで編集不可 | Inspector が effect 名と削除ボタンのみ。`effectRows` で blur の sigma・shadow の sigma/offset/opacity を編集可能にし、`vec2ParameterValue` で vec2 を読む | Blur 追加→「ぼかし」行表示→値変更が rev 8 のイベントとして記録・プレビューにぼかし反映 |
| レイヤー削除が GUI 未接続 | `node_remove` は実装済みだが UI なし。`removeLayer` を Inspector の「編集」セクションに接続 | 「Matte rectangle」削除で一覧とビューアから消失・rev 6・undo 可 |
| Sequence 作成が GUI 未接続 | 空状態が「共有 API で作成してください」表示のみ。「シーケンスを作成」ボタンを追加（映像・音声各 1 トラックの最小 Sequence） | wire 形式は `Sequence`/`Track` のスキーマと既存テストフィクスチャで照合済み。実機でのボタン操作は未実施（空のシーケンス状態のプロジェクトが手順上必要） |

- `modifier_insert` / `modifier_replace` / `modifier_remove` / `modifier_reorder`

## 既知の限界・残件

- 出力先テキストフィールドは AX 経由の直接入力がモデルに伝わらないことがある。保存パネル経由では正しくコミットされる。実ユーザー操作では問題にならないが、AX テスト容易性の改善余地あり
- 保存パネルのパス移動ショートカット経由で `:` 区切りの擬似パスが入力されるケースを観測。アプリ側のパス正規化の問題ではなく macOS 保存ダイアログの入力解釈。実害確認なし
- ProRes 72 フレーム書き出しは約 8.5 分。進捗・残り時間・中止は正常動作
- 保存が数秒かかる間は全編集操作が無効化される（仕様通りだが連続操作では待ちが発生）
