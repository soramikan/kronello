workspace test は既存の大きい CJK フォント・render 回帰を完走させるため test profile の opt-level を1にする。debug_assertions、テスト内容、feature は変更しない。同じ worktree の target directory を使い、別 target directory は作らない。

## 実装上の決定

- 公開 API 版はファイル名・$id・x-api-schema-version で表す。既存 envelope に必須 version field を加えない。
- registry refs は request payload / successful value を指し、transport の operation / status / kind envelope と区別する。FFI / MCP で同じ型と registry を再利用する。
- scene.query は全 authored node を返し、時刻で絞らない。kind の CompositionInstance に local TimeMap を保持する。expanded node は local active_range と enclosing placement を明示する。
- property.sample は root Composition と runtime key を明示し、単位は共有 descriptor を読む。全値成功時だけ一つの result を返し、失敗時に部分 sample を返さない。有効な Modifier と Expression は未対応として型付きエラーを返す。
- capabilities の backend は実装済み経路の列挙で、device availability の診断ではない。effects は本 worktree では空。media は上位から注入する構造化拡張とし、FFmpeg を API-001 が呼ばない。
- history は全保持 Event の Undo chain を先に判定し、その後に session filter / pagination する。各ページの revision / Event は一つの transaction で取得する。ページをまたぐ固定 snapshot cursor は未実装。
- filesystem locator の URI scheme は access 前に拒否する。Project 内の asset extension の locator slots も対象とし、一般の text / name を命令扱いしない。
