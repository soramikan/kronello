# FX-001 基本エフェクトの検証

FX-001 は `SceneNode.effects` の順序付き stack、`kronello.gaussian_blur` / `kronello.drop_shadow` の意味版 **1**、ROI の逆伝播、CPU oracle と GPU compute pass を追加する。文書は schema_version 1 の追加フィールドで、空 stack は省略できる。未知 id・未知 parameter variant・未知フィールドは保存時に保持し、必要な effect / 意味版は最終レンダーで `UNSUPPORTED_FEATURE` とする。

## モデル・評価・処理順

`Effect::Known(EffectDefinition)` は `effect_id`、`version`、`parameters` を持つ。`Effect::Opaque` は解釈できない JSON 値をそのまま保持する。`EffectParameters::GaussianBlur` は sigma、`DropShadow` は sigma / offset / color / opacity の、所有ノードの `PropertyId` を参照する。

`kronello.effect.sigma` は非負 Scalar / `design_px`、offset はローカル Vec2 / `design_px`、color はタグ付き straight Color、opacity は `[0,1]` Scalar / 無次元。既存の instance-aware `DependencyGraph` で全 Property を任意の有理数時刻に評価するため、Constant / Curve / Modifier を別実装しない。解決時にも型・単位・最終値を検証する。sigma / offset の絶対値は 1,000,000 以下、stack は 16 entries 以下。

処理順は content / child の隔離合成 → node opacity 一回 → authored 順の effect → matte。shadow はその段階の source alpha を使う。Group の子へ opacity / effect を配らない。effect のローカル sigma は world transform の等方倍率、offset は同変換の線形部分で root Composition 空間へ写す。回転・反転・等方拡大縮小を扱い、正の sigma に非一様 scale / shear を適用する処理は `UNSUPPORTED_FEATURE`。sigma 0 の shadow offset は一般の affine で写せる。

## Kernel と色・alpha

意味版 `fx001-separable-gaussian-transparent-v1`。

1. 出力倍率を掛けた軸別 sigma を float32 に固定する。各軸の radius は `ceil(3 * sigma)`、上限 1,024 output pixels。sigma 0 は `[1]` の identity。
2. 整数 tap `i = -radius..radius` の重みは `exp(-0.5 * (i / sigma)^2)`。float64 で計算・総和正規化し float32 にする。CPU / GPU に同じ weights を渡す。各 pass で float32 の同じ順序の weight 総和で割り、float32 丸めによる全不透明 alpha の 1 超を避ける。
3. 水平 → 垂直の separable convolution。端の範囲外は透明ゼロ。端で欠けた tap に合わせた再正規化はしない。RGBA すべてを作業用線形 premultiplied のまま畳み込む。
4. shadow は blurred alpha を offset 分だけ移す。非整数 offset は透明境界の bilinear（floor と次画素、水平 lerp → 垂直 lerp）。タグ付き straight color を sRGB decode / 原色変換 → premultiply → opacity の順で control parameter として変換し、blurred alpha を掛ける。`source + shadow * (1-source.a)` で下へ合成する。

GPU の水平・垂直・shadow 合成面は RGBA16F、CPU oracle は float32 で各面を独立計算する。CPU の重み計算・入力色の変換は control upload であり、画像の upload / effect の CPU fallback ではない。GPU は既存 pass と共有する sticky validation status で非有限値、alpha 範囲違反、RGB の binary16 上限超過を拒否する。外部 epsilon は内部 blur へ適用しない。

## ROI と bounds

`DagNode::Effect` は画像 source を持つ。`PixelEffect::required_input(output)` は blur の radius 分を広げる。shadow は元の output と、offset の逆向きに移した output の floor / ceil 領域を blur halo 分広げたものの union。stack / Group / mask / 共有入力を DAG の逆順に伝播し、共有 source の要求は union する。要求座標は元の `OutputRegion` の画素格子。

初期 executor は要求領域すべての union を一つの `execution_region` に割り当てる。元の画素倍率・sample lattice を保ち、geometry を拡張領域へ lower し、effect を実行後に backend で要求画素へ crop する。Composition / 元の要求矩形の端で source を事前 clip しない。ノードごとの tile allocation と性能最適化は今回の範囲外。拡張後も既存 pixel / surface memory budget を検査する。

`RenderDag::bounds()` は元の要求画素座標で `NodeBounds { ink_bounds, visual_bounds }` を返す。ink は transform 済み coverage geometry（stroke は join を含む保守的拡張）、visual は child visual の union と effect の実際の離散 halo を反映する。shadow は source bounds と offset 後の blur bounds の union。sigma の丸めを含めるため bounds は出力倍率に依存する。Group / mask の bounds は保守的で、透明画素や mask による縮小を使った最小矩形にはしない。text の layout_bounds は従来どおり組版 IR に残る。

`RenderSnapshot.semantic_versions.effects` と frame / sequence metadata に effect id → 意味版を固定する。復元時に不足版を補わない。`RasterCacheKey::for_dag` は effect params、kernel / effect 意味版、順序付き upstream content identities、ROI、作業色空間、backend namespace を含む。CPU の effect frame は別 key domain `effect` で既存 raster LRU の予算を共有する。GPU texture cache は追加しない。
