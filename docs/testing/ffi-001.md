| 条件 | 証跡 | 結果 |
|---|---|---|
| 1. ## JSON 計測

要求 fixture は `examples/ffi-json-benchmark.request.json`。
一つの Node property を時刻 `0` / `1/60` で sample する310-byte Request。
応答 fixture は実 CLI / service で取得した二つの Vec2 sample を含む
`examples/ffi-json-benchmark.response.json`。
Rust の compact response は454 bytes、Swift の再 encode は446 bytes
（16.0 / 12.0 等の整数値の number formatting の差）。
Swift poll envelope は559 bytes。

```sh
cargo run -p kronello-ffi --example json_cost --locked
apps/macos/.build/direct/KronelloJSONBenchmark examples/ffi-json-benchmark.request.json
# host SwiftPM build 後の同じ executable:
swift run --package-path apps/macos --skip-build KronelloJSONBenchmark examples/ffi-json-benchmark.request.json
```

10,000回の一回当たり平均、単位 µs:

| 実装 | request decode | request encode | response encode | response decode | native framing |
|---|---:|---:|---:|---:|---:|
| Rust dev / unoptimized | 21.305 | 13.295 | 21.200 | 未計測 | worker の Response→Value→JSON text→poll envelope encode 合計72.322 |
| Swift 6.4 / Onone | 19.424 | 7.976 | 16.756 | 36.363 | poll envelope decode 6.389 |

共有 machine の単回計測であり、release 性能、percentile、4K pixel JSON、通知の巨大 job list、
queue / copy / store / shader validation / GPU present latency の計測ではない。
native pixels は JSON を通さず、redraw 要求の時間・領域のみ JSON にする。
性能目標の確定（OQ-14）や JSON の撤廃をこの数値から決めない。
