## 契約

version 1 の versioned effect として次の 13 種を実装した（descriptor は 55xx 番台、semantic version は 1）。

- `kronello.grain` — `amount`(0..=1)・`size`(design_px, 正)・`monochrome`・`seed`。固定 seed の決定的セルノイズ。seed は resolved 31 bit 整数で、DAG builder がシーン時刻を畳み込み時間連続性を持つ。alpha を保存する。
- `kronello.mosaic` — `block_size`(design_px, 正)・`basis`(`center`/`edge`)。ブロック単位の量子化で、basis が参照画素の基準を決める。
- `kronello.invert` — `channel`(`rgb`/`red`/`green`/`blue`/`alpha`)。選択チャンネルを反転し、非選択と alpha 規約を保持する。
- `kronello.channel_mixer` — 4x4 係数行列（row-major premultiplied RGBA、row = output channel）。
- `kronello.tint` — `map_black`・`map_white`・`amount`(0..=1)。輝度を黒白マップ色へ `amount` だけ寄せる。
- `kronello.directional_blur` — `angle_degrees`・`length`(design_px)。ノードローカル角度を DAG mapper が出力ラスタへ回転する。
- `kronello.radial_blur` — `mode`(`spin`/`zoom`)・`amount`・`center`(design_px)。spin は角度量、zoom は内側への 0..=1 の extent。
- `kronello.displace` — `channel_x`/`channel_y`(`red`/`green`/`blue`/`alpha`/`luminance`)・`displacement`(2x2、design_px/単位値)。別サーフェスの map を明示 secondary 入力（`DagNode::EffectMap`）として参照する。map 欠落・重複は型付き拒否。
- `kronello.generate` — `generator`(`gradient_linear`/`gradient_radial`/`checkerboard`/`grid`)・`color_a`/`color_b`・`point_a`/`point_b`・`cell_size`・`line_width`。ソース不要の `DagNode::Generate` 葉ノードで出力面を覆う。
- `kronello.audio.delay` — `delay_ms`（48 kHz 整数サンプルへ量子化）・`feedback_db`(<=0)・`wet`/`dry`。
- `kronello.audio.reverb` — `decay_s`(RT60)・`damping`(0..=1)・`wet`/`dry`。ADR-0139 の決定的並列フィードバックコム（コム長 1157/1361/1499/1723 サンプル、`g = 10^(-3 D / T60)`、ループ内一段ローパス）。外部 IR は後続。
- `kronello.audio.pitch` — `semitones`。ソースステージの WSOLA 拡張で、ウィンドウは `rate = 2^(semitones/12)` の stride でソースを読み、カーソルは実時間のまま持続を保存する。generator ソース・reverse retime は型付き拒否。
- `kronello.audio.gate` — `threshold_db`・`attack_ms`・`release_ms`・`hysteresis_db`。

共通の規約は次の通り。

- すべて premultiplied working space で評価し、alpha 契約は各 effect で明示する（grain / tint は alpha 保存、invert は選択時のみ alpha 反転）。
- directional / radial blur は blur 支持だけ `halo` / `required_input` / `output_bounds` を拡張する。displace は displacement 量だけ bounds を広げ、map 側は全面参照する。
- 非有限値・範囲外・不正 enum は `resolve` / `validate` の型付き `EffectError`。GPU 非対応のノード・効果組合せ（`EffectMap` に Displace 以外、`Generate` に Generate 以外）は型付き拒否で、黙った近似をしない。
- kernel は FX-008 系 WGSL op 14–22、displace の map は binding 6。semantic version は 13 効果とも 1 で `SemanticVersions::current()` に登録する。
