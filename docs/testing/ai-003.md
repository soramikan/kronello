## 受け入れ対応

- 被写体追従リフレーム: `kronello-scene`（`src/reframe.rs`）は versioned `TrackingDataAsset`（TRACK-001）の追従点を confidence 加重で合成し、`SmartReframeSettings` の seed 選択（省略時は全 seed）・時間平滑・padding・max zoom・target aspect・easing に従って source pixel の crop window を決定論的に返す。追従点不足・stale source・不正設定は型付き失敗であり、center crop への silent fallback は行わない。
- crop の評価・描画経路: `kronello.media.crop_origin` / `kronello.media.crop_size` の builtin descriptor（Vec2・DesignPx）を追加し、crop 値は通常の property 評価経路で解決される。`SceneContent::Video` は optional crop を保持し、media content は locked source 寸法との bounds を検査する。DAG lowering・software media render・layout extent は crop window に従い、crop 未対応の GPU 経路は黙って無視せず型付き拒否する。crop size が 0 の場合は crop なしとする。
- responsive layout との組み合わせ: `TemplateConstraints.smart_reframes` の `SmartReframeRule` は aspect variant ごとの constraints に属し、選択された edition の rule が `RuntimePropertyKey::LayoutValue` 経由で crop origin/size を注入する（LAYOUT-001 の shared dependency path と同じ優先順位）。rule の node・tracking asset・crop property の存在と種別・settings・tracking source hash を build 時に検証する。
