# GUI-010 macOS カラー Inspector — 受け入れ記録

状態: `m7-lane-d2` の作業ツリーで実装と自動検証を完了し、モデル / コマンド層の条件は確認済み。ネイティブ GUI の実機確認は 2026-10-07 に `integration-003.md` の GUI 経路検証として実施済み。

## 実装した範囲

- 「カラー」Inspector セクション（新規 `ColorInspector.swift` の `ClipColorInspector`）を非 audio クリップの Clip Inspector に追加。追加・編集・削除のすべてが既存の `clip_set_effects` コマンド経路（`replaceClipEffects` / `setClipEffectParameter`）を通り、Undo と revision 競合は共通パイプラインに従う。
- 対応 effect（COLOR-002、`version: 1`）:
  - `kronello.color.exposure`（`color_exposure`）: 露出（EV）・オフセット
  - `kronello.color.levels`（`color_levels`）: 入力黒・入力白・ガンマ・出力黒・出力白
  - `kronello.color.curves`（`color_curves`）: x/y 制御点の行ベース編集（追加・削除・数値編集）
  - `kronello.color.hsl`（`color_hsl`）: 色相（度）・彩度・明度
- 追加時の既定値は恒等（exposure 0 / offset 0、levels 0–1・gamma 1・0–1、curve は (0,0)–(1,1) 2 点、hue 0・saturation 1・lightness 0）で、挿入直後は描画が変わらない。パラメータは `kronello.effect.*` ディスクリプタの constant Property として clip.properties に追加し、effect 定義は PropertyId を参照する。
- 未追加の effect だけを「カラー補正を追加」ポップアップに列挙する。既存の blur / shadow や無関係な clip properties、effects の順序は保持する。
- パラメータの Property 参照元が constant でない（curve / expression）場合はフィールドを無効化し「読み取り専用」を表示する。`setClipEffectParameter` も同じ条件をガードし、`UNSUPPORTED_FEATURE` の型付きエラーにして値の上書きを防ぐ。
- カーブ編集: 制御点は `curveTableValue` が x 昇順へ正規化し、共有モデルの契約（2–64 点・x 厳密増加・x/y ∈ [0,1]・有限値）を満たす表だけを送信する。点削除は 2 点未満にしない、追加点は最大ギャップの中点に挿入する。グラフ描画型のカーブエディタは本レーンの範囲外。

## モデル / コマンド層で確認済みのこと

- `clip_set_effects` は properties と effects の配列を原子的に差し替える 1 Event で、Undo は最新 Event から遡って復元する。
- `Effect::validate` がパラメータの `ValueType` / `Unit` を照合し、resolve が exposure ±1024・levels `in_white > in_black`・gamma > 0・hue ±1e6 などの境界を検査するため、UI の実用レンジを越える値は型付きエラーになる（UI は creative range でクランプ）。
- `Effect::references` により clip-level property のアニメーション（curve 参照）を残したまま編集を拒否する。

## 制約・既知の限界

- カーブは数値行エディタのみ。グラフ上の直接ドラッグや接線ハンドルは対象外（後続タスク）。
- levels の各スライダーは 0–1（out 系は -1–4）でクランプするが、モデルの受理範囲は ±1e6 であり、`in_white <= in_black` 等の不整合は送信時の型付きエラーとして返る。
- ネイティブ GUI の実機確認は `docs/testing/integration-003.md` の「GUI 経路の検証結果」で実施済み（2026-10-07）: Inspector のカラーセクションと「カラー補正を追加」の表示、exposure +1 が適用されたクリップの明度上昇を実画面で確認した。パラメータ変更の即時反映・Undo の目視はモデル層テストで担保し残件としない。
- `ClipAuthoring.swift` / `EditPage.swift` は D1 レーンと並行変更の可能性が高い。色効果の構築は `KronelloAppModel` 側の spec 駆動に集約し、`EditPage` 側は 1 セクションの挿入のみとした。
