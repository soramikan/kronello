## 受け入れ条件と証拠

| 条件 | テスト / 手順 | 状態 |
|---|---|---|
| 1. dash array / offset、offset animation | vector unit `vec005_dash_phase_odd_zero_and_budget`（奇数・負 offset wrap、zero dash、負 / 非有限 / 全 zero、予算超過）、`vec005_closed_seam_preserves_join_and_contour_phase`（閉じ辺、seam join、複数 contour）。render `vec005_offset_animation_instances_and_raster_identity`（異なる instance local time、Curve、任意時刻再評価、geometry hit / raster miss） | CPU 合格 |
| 2. center / inside / outside | GPU crate CPU unit `vec005_alignment_uses_fill_rule_holes_and_reversed_winding`（evenodd / nonzero、穴、方向反転）、`vec005_zero_dash_caps_and_affine_width_have_analytic_support`（butt / round / square の zero dash）、render `vec005_invalid_dash_open_alignment_budget_and_version_are_typed`（開 contour の拒否） | CPU 合格、Metal pending host run |
| 3. 非一様 scale / skew の線幅 | render `vec005_nonuniform_skew_bounds_and_roi_are_conservative`（3 alignment、3 時刻、両作業色空間、全画素と cropped ROI、ink / visual の包含）、GPU crate の解析的 affine width test と `cpu_vec005_catalog_rasterizes_local_affine_and_alignment`（reflection を含む） | CPU 合格、Metal pending host run |
| 旧 snapshot / 版の拒否 | `vec005_legacy_snapshot_pixels_and_unknown_versions`（旧文字列の snapshot と新 snapshot の旧 stroke が同じ画素、未知版拒否、旧 pin で新 options 拒否）。既存 `supported_stroke_styles_nonuniform_transform_and_zero_scale` は旧版の非一様拒否を維持 | CPU 合格 |
| 共通 authoring / 保存 / undo / schema | service `vec005_shared_shape_and_offset_curve_edits_roundtrip_undo_and_typed_errors`（ShapeSet、NodePropertyInsert、PropertySourceSet + Curve、JSON command decode、型付き dash / 未知版エラー、atomic rejection、独立した undo）。api / nle_schema / Swift generator | targeted / schema 検証合格 |
| CPU / WGSL の比較 fixture | `cpu_vec005_golden_samples_avoid_discontinuity_ties`（全新規シーンの逆写像と fill contours を各軸 ±1e-5 摂動しても全画素不変）、`vec005_inverse_mapping_overflow_is_typed_before_sampling`、既存 Naga parse / validation、golden catalog / manifest test | CPU 合格、実 GPU 比較は pending host run |

新規 API は `Stroke.options: StrokeOptions?`（Rust 内部は Box）、`StrokeAlignment`、
`geometry_version` / `fill_rule` / `dash_array` / `dash_offset`。
共通編集 command を拡張型で使い、入口専用 command や状態は作らない。
`kronello.shape.dash_offset` は Scalar / DesignPx の通常 Property。
版は旧 `vec003-centered-stroke-v1` と明示新 `vec005-local-stroke-v2`。
エラーは `STROKE_INVALID_DASH` / `STROKE_BUDGET_EXCEEDED` / `STROKE_OPEN_ALIGNMENT`、
未知版は `UNSUPPORTED_FEATURE`。非有限 JSON は既存 decoder / FiniteF64 の拒否経路。
非有限・特異 / float32 で近退化の写像は型付き入力エラーを返し、CPU fallback はしない。
