# FX-003 拡張 blend mode とパラメータ化トランジションの検証

現在の状態（2026-10-07）: M7 Lane C の作業ブランチ `m7-lane-c` で実装・検証を完了した。コードのコミットは `ba4f429`、golden baseline の採用コミットは本書と同じ後続コミット。`docs/backlog/backlog.json` の状態更新はこの文書の範囲外。

## 契約

[ADR-0109](../adr/0109-blend-modes-and-parameterized-transitions.md) に従い、`BlendMode` を W3C Compositing and Blending の 19 モードへ拡張し、`TransitionKind` に `wipe` / `slide` / `dip` を追加した。

- blend は `kronello.blend_mode` の単一 constant プロパティで authored（animation 不可・重複不可）。separable 15 + non-separable 4 の wire name は snake_case の閉集合で、未知値・Curve source は `INVALID_BLEND_MODE` 系の型付きエラー。CPU oracle（`kronello_gpu::color::blend`）と `scene.wgsl` が同じ式を共有し、straight operand → blend → premultiplied 合成に戻す。HDR・負値は clamp しない。operation id は `Normal=1, Multiply=5, Screen=6, …, Luminosity=23` で固定。
- transition は `Transition.params` が kind と対応する payload（`wipe.direction` / `slide.direction` / `dip.color`）を要求する。`crossfade` は `params: None` のみで従来と完全互換。kind と payload の不一致・区間不整合は `INVALID_CLIP`、未知 version は `UNSUPPORTED_FEATURE`。
- wipe は指定方向からのハードエッジ矩形 reveal、slide は incoming clip のみ平行移動（outgoing は静止）、dip は前半で dip color へ fade、後半で dip color 上に incoming が fade in。音声は kind に関係なく線形 crossfade のまま。
- scene IR では wipe → `SceneTransition::Reveal`（matte）、slide → ノード平行移動、dip → `SolidRect` underlay + 段階 opacity。raster cache key と `semantic_versions.blend` に mode / 版が入る。

## golden シーン

カタログに 5 シーンを追加し、共通 baseline を **49 シーン・49 comparison frames** に更新した。

- `fx003-blend-separable`: 48×48、4×4 tile に 15 separable モード。backdrop / source は作業線形の非単調な色で、source tile を 2px ずらして backdrop 単独・blend 重なり・部分 alpha 端を同時に写す。
- `fx003-blend-nonseparable`: hue / saturation / color / luminosity の 4 tile。
- `fx003-wipe`: 左半分を alpha matte で reveal する wipe 中点相当。左側が incoming（青）、右側が outgoing（赤）。
- `fx003-slide`: incoming（青）が右半分へ平行移動した中点相当。outgoing（赤）は静止。
- `fx003-dip`: dip 色（黒）が完全不透明の下敷き、その上に incoming（青）が opacity 0.5 の中点以降相当。実測 `[0,0,0.5,1]`。

`tests/golden/scenes.json` の解析 contract に `fx003-wipe-reveal`（operation `wipe-reveal`）と `fx003-dip-opacity`（operation `dip-opacity`）を追加し、`kronello-testkit` の contract テストで 4 方向の reveal 矩形と dip の under/over 曲線を別計算で検証した。
