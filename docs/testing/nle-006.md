## 受け入れ条件と証拠

| 条件 | テスト / 確認内容 | 状態 |
|---|---|---|
| 1: TimeMap の曲線化によるスピードランプと freeze frame/hold を実装する | `PiecewiseTimeMap` の local 制約を非減少に緩和（`local[i] == local[i+1]` が hold 区間、逆単調は `UnsupportedMapSlope` のまま）。`is_hold` / `slope_at` を追加し、`inverse_canonical` は hold 内の local に区間開始 parent を返す決定的規則とした。`contracts::piecewise_hold_segments_pin_local_and_invert_deterministically`: hold 内の `map` が固定 local を返し、端点と連鎖 hold、逆写像の決定性を確認。`nle5::clip_time_set_piecewise_ramp_and_hold_validate_domain`: `clip_time_set` が piecewise map 全体を受理し、domain 被覆・ソース実尺・`Reject` ポリシ違反を計画時に型付き拒否。`nle5::clip_freeze_splits_into_hold_and_undoes_atomically`: `clip_freeze` が配置を `at` で分割し、右クリップが `[(0,0),(duration,0)]` の hold map と `at` 時点の `source_in` を持つこと、決定的な右 ID（`freeze_right_id`）が plan/apply で一致し、undo で元配置へ完全復元することを確認 | CPU 検証 |
| 2: 音声の AudioRetimePolicy との整合と型付き拒否を検証する | `audio4::piecewise_hold_mixes_silence_and_ramps_resample_at_segment_speed`: hold 区間のミックス出力は全サンプル `[0,0]`（ソース時刻が進まないため無音）、前後のランプ区間は各区間の線形速度でリサンプルされることをサンプル精度で確認。`nle5::clip_freeze_rejects_boundaries_links_transitions_reverse_and_reject_audio`: `Reject` ポリシの音声クリップへの freeze は計画時に `UNSUPPORTED_FEATURE`。`resample` / generator 経路の両方が `hold_silent` で区間判定し、`ReverseResampleV1` も同一経路で hold を無音化 | CPU 検証 |
| 3: freeze の前提条件と Undo 原子性 | 同テストで `at` の境界・範囲外は `INVALID_EDIT`、リンク済みは `LINKED_EDIT_REQUIRED`、トランジション端点は `TRANSITION_EDIT_CONFLICT`、逆再生クリップは `UNSUPPORTED_FEATURE`、caption ソースは `UNSUPPORTED_FEATURE`、protected composition 内容は `PROTECTED_INTERVAL`、ロック済み track は `TRACK_LOCKED`（NLE-005 の battery 側）を確認。いずれの拒否も plan 失敗で文書・revision を変えない | CPU 検証 |
| 4: GUI での速度ランプ表示と freeze 操作 | `EditClip.timeMapKind` / `speedLabel` で piecewise map を「速度ランプ」と表示し、レーン上に `slidersHorizontal` アイコンの非線形インジケータを追加。インスペクタに「再生ヘッドでフリーズ」ボタン（`clip_freeze` へ dispatch、再生ヘッドが clip 内部かつ非ロック時のみ有効）を追加。速度・逆再生の編集は Linear map のみに限定し piecewise は読み取り専用表示 | ソース検証・host build 待ち（NLE-005 の記録と同じ） |

## Public API / schema

- `PiecewiseTimeMap::is_hold` / `slope_at` を `kronello-time` に追加。map の JSON wire 形は不変（`points` の `parent` / `local`）。`TimeMap` の schema 説明文を hold 区間を含む記述に更新。
- `TimelineCommand::clip_freeze { sequence, clip, at }` を追加。右クリップ ID は `(clip, at)` から導出する決定的 ID で、plan と apply が同一結果を生成する。
- `schemas/project-v1.schema.json` / `schemas/api-v1.schema.json` / `GeneratedAPI.swift` を再生成。schema 番号は 1 を維持。
