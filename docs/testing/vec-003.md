# VEC-003 の検証

この文書は VEC-003 実装時の履歴。現在の gradient 拡張は [VEC-004](vec-004.md) / ADR-0066 を参照する。
VEC-004 の正しい options / geometry / Text gradient payload は実行対象となり、下表の opaque テストは
不正な旧提案 JSON と VEC-005 の保持・拒否を検証する。過去の実機結果や意味版は当時のまま残す。

線の中央配置、join / cap / miter limit、Shape の線形・放射 gradient に限る。意味版は coverage `vec003-grid4-v2`、stroke geometry `vec003-centered-stroke-v1`、gradient interpolation `vec003-linear-premultiplied-pad-v1`。既存 vector `render001-kurbo-flatten-v1` / color `gpu002-color-v1` は維持する。

| 受け入れ条件 | 再現するテスト |
|---|---|
| join / cap 共通幾何と limit 4・bevel fallback | GPU crate unit `cpu_caps_have_analytic_extent_and_corner_definition`、`cpu_joins_miter_limit_and_reversed_winding_are_analytic`、`cpu_degenerate_contours_and_zero_width_do_not_create_spurious_regions`。辺 / 端・反転方向・閉 contour・limit の上下を解析値で確認 |
| 線形 / 放射、fill / stroke、pad | scene suite `cpu_gradient_pad_premultiplied_equal_offsets_and_working_conversion`、`gpu_stroke_styles_and_gradients_match_cpu_in_both_working_spaces`、カタログの全画素 CPU / GPU 照合 |
| 作業用線形 premultiplied と透明 stop | 同上。透明青と不透明赤の中点は `[0.5,0,0,0.5]`、straight 補間後に premultiply する誤結果 `[0.25,0,0.25,0.5]` と区別。Rec.2020 原色変換、HDR stop、同位置 stop も検証 |
| 色・offset のアニメーション | render suite `gradient_stop_color_and_offset_animate_through_scene_evaluator`、`gpu_gradient_dag_transform_and_animation_match_cpu_reference`。有理数 0 / 1/2 / 1、回転・拡大・移動の DAG lower を両作業空間で比較 |
| stop 不正値は型付きエラー | `invalid_gradient_stops_and_geometry_fail_with_typed_shape_errors`、GPU paint の validation。負 / 1 超 / 非有限・順序逆転・線形端点一致・半径 0 / stop 数不足 |
| metadata と cache の区別 | animation test の意味版確認、`gradient_color_changes_invalidate_raster_and_geometry_changes_invalidate_both`。色変更は geometry hit / raster miss、寸法変更は両方 miss |
| 未知 / 不正な gradient payload と VEC-005 は保持して最終出力拒否 | `malformed_gradient_and_vec005_payloads_roundtrip_but_fail_final_render`、`malformed_text_gradient_is_preserved_as_opaque_and_snapshot_refuses_it`、`supported_stroke_styles_nonuniform_transform_and_zero_scale`。options 外の spread / units / transform 等の不正な旧提案 JSON、不完全な conic、dash / alignment の値往復と `UNSUPPORTED_FEATURE`。正しい VEC-004 payload は実行対象 |

追加 golden 定義は `stroke-joins`、`stroke-caps`、`stroke-miter-limit`、`gradient-linear-fill-stroke`、`gradient-radial-fill-stroke` の 5 シーン。従来 16 に加え、計 21 シーン / 21 comparison frames。manifest は線幅・join / cap / limit、全 stop、paint 逆写像、追加意味版を記録する。4×4 サンプル、RGBA16F、QA-001 の既定 `compare_pixels` 許容誤差を維持し、エッジを除外しない。

## 検証コマンドと状態

worker sandbox は Metal adapter 不在。CPU / Naga / schema / workspace は worker が実行し、GPU 実測は supervisor が host で実行して返した結果である。M1 host での UPDATE は候補生成と CPU oracle 照合であり、M4 baseline の登録・固定環境比較・許容誤差校正ではない。

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --exclude kronello-framebridge --exclude kronello-gpu --locked -- --skip gpu_
cargo test -p kronello-gpu --locked -- --skip gpu_
python3 scripts/backlog.py check
```

### Worker のローカル検証

- `cargo fmt --all --check`: exit 0。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`: exit 0。
- `cargo test --workspace --exclude kronello-framebridge --exclude kronello-gpu --locked -- --skip gpu_`: exit 0、合計 **264 passed**、GPU テスト 4 filtered。公開 project Schema の生成物照合を含む。
- `cargo test -p kronello-gpu --locked -- --skip gpu_`: exit 0、**17 passed**（unit 3、contracts 5、golden カタログ 1、scene 8）、17 filtered、固定環境 golden 1 ignored。Naga parse / validation と解析値・カタログ / manifest の対応を含む。
- `cargo run -p kronello-model --example project_schema --locked > schemas/project-v1.schema.json`: exit 0、公開 Schema を再生成。
- `python3 scripts/backlog.py check`: exit 0、60 tasks。

実装途中の stop descriptor 重複と miter limit の浮動小数点境界テストを修正して通した。GPU 名を除外しない `gradient` filter の試行は `ADAPTER_UNAVAILABLE` で失敗し、CPU fallback は行っていない。上記の CPU 検証では `--skip gpu_` を使った。

### Supervisor の M1 host 検証

Apple M1 / Metal（IntegratedGpu）、MacBookPro17,1、16 GiB、macOS 27.0（build 26A428）、wgpu 30.0.1。HEAD `a7f7e82f99df201ed7cc3f3d7d9fbcf49a2d2dc1` と未コミットの VEC-003 差分を対象とした。

- `WGPU_BACKEND=metal cargo test -p kronello-gpu --locked -- --nocapture`: exit 0、**34 passed**（unit 3、contracts 13、golden カタログ 1、scene 17）、固定環境 golden 1 ignored。
- `WGPU_BACKEND=metal cargo test -p kronello-render --test render --locked -- gpu_ --nocapture`: 最終実行 exit 0、**3 passed**、24 filtered。新規 gradient DAG の移動・回転・拡大・stop アニメーション、既存 Shape / Text / matte / sequence の GPU / CPU 照合。初回はテストで rotation に `Scalar` を渡し `ValueTypeMismatch { expected: Angle, actual: Scalar }` で失敗した。`Value::Angle` に修正してこのコマンドだけを再実行した。修正後の fmt と `cargo clippy -p kronello-render --all-targets --locked -- -D warnings` も worker で exit 0。
- `WGPU_BACKEND=metal KRONELLO_GOLDEN=1 KRONELLO_GOLDEN_UPDATE=1 KRONELLO_GOLDEN_OUTPUT=<fresh target/golden/run.vec003.* directory> cargo test -p kronello-gpu --test golden --locked -- --ignored --nocapture`: exit 0、**1 passed**、21 scenes / 21 frames を CPU oracle に照合。出力は `target/golden/run.vec003.pZ7hXx/`。worker も `report.json` と `candidate/environment.json` を読み、上記 scene / frame 数と platform、`eligible_reference_hardware=false` / `candidate_may_be_adopted=false` / candidate-only を確認した。

M4 の基準画像・fingerprint の登録、固定環境 baseline 比較・許容誤差校正、新しい描画の Windows / Linux 実機検証、性能測定は未実施。M1 候補を M4 基準として保存していない。host 成功はこれらの検証を含まない。
