## 変更の範囲

`kronello-model::ShapeGeometry` に `MorphPath` / `TrimmedPath` を追加し、既存 Property・共有編集 API・保存・render/cache/bounds へ接続した。SVG は [ADR-0094](../adr/0094-explicit-path-operations-and-bounded-svg.md) の限定 Path / solid fill subset として `svg.inspect` / `svg.export` / `svg.import_plan` を追加した。SVG の対応表・拒否理由を見ずに完全対応と扱わない。

## 主担当のGUI確認用fixtureと手順

[examples/m5-vector.project.json](../../examples/m5-vector.project.json) は実shared APIの保存文書をexportした、font / asset不要のfixture。上記scriptが作った `target/m5-acceptance/vector-transports/vector-gui.kronello` を開けば同じ最終文書を編集できる。GUI用projectは独立のrevision1で、上記のrevision3と同じhashを要求しない。

1. Motionで `Morph curve` と `Trim closed loop` を表示。Dope sheetの各layerを展開し、必要なら「値の列を開く」を押す。汎用Property表示が `Morph progress` / `Trim start` / `Trim end` / `Trim offset` を表示する。
2. 時刻0 / 12 / 24 frames（24fps、0 / 1/2 / 1秒）へ移動すると赤い曲線の幅が増える。時刻0で `Morph progress` を0.5へ変更すると既存Curveの現在時刻keyを変更して赤い形が広がる。Undoで元のkeyと描画へ戻す。
3. 緑のTrimは初期値0.19 / 0.81 / -0.4。`Trim end` を0.19へ変更すると空選択になって消える。Undoで復元する。`Trim start`=0 / `Trim end`=1で全closed矩形となる。各操作のUndo、revisionと外部exportのProperty値を確認する。
4. 部分選択に戻してoffsetを変更すると選択区間が閉輪郭上を巡回する。全長選択ではoffsetで形が変わらないのが契約。Path自体はSVGで明示した入力であり、control point編集UIを実装したという主張ではない。

GUI専用の操作は追加せず、既存のnumeric Property / Curve編集を使う。直接GUI操作・OS compositor後の画素確認は主担当が別途記録する。
