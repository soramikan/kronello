# SUB-001 検証

状態: `done`。`m7-lane-b` の作業ツリーで受け入れた。main への統合・各 OS CI の保証とは区別する。[ADR-0107](../adr/0107-caption-track-and-cue-model.md) に基づく。正本の条件は[バックログ](../backlog/backlog.json)の「caption track と字幕 clip kind を sequence モデルと schema に追加する」「文字装飾（フォント・色・縁取り・背景・位置）を評価可能な Property として表す」「未知の版・未対応機能は型付き拒否とし、版管理の規約に従う」である。

## 受け入れ対応

- caption track と字幕 clip kind: `TrackKind::Caption` と `SourceRef::Caption { caption }` を追加し、cue 本文は `Project.captions` の版付き `CaptionDocument`（`version = 1` のみ採用）として保持する。`ClipKind::Caption` は `sequence.query` で報告され、`edit.plan` / `edit.apply` と CLI / MCP の共有コマンドで caption track の追加・clip 配置ができる。`schemas/project-v1.schema.json` と `schemas/api-v1.schema.json` を再生成した。
- Property としての装飾: `CaptionStyle`（フォント hash 固定・サイズ・fill・outline・background）と `CaptionPlacement`（9 方向 anchor・有理数 safe area inset・offset）は clip `properties` の定数 override で解決する。字幕専用 descriptor（`caption.font` など 9 件）は共有 registry に登録し、Curve・Expression・Modifier の字幕プロパティ指定は型付き拒否とする。
- 型付き拒否: 未知 `version`・未知フィールド（`deny_unknown_fields`）・grapheme 境界をまたぐ span・重複する cue・非 caption track への caption clip・逆方向の混在・caption clip の `source_in != 0` や非恒等 `time_map` はすべて型付きエラー。`CaptionDocument::validate` と `Sequence::validate` が文書境界で、`RenderSnapshot::for_target` が snapshot 境界で検査する。
