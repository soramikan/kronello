# FX-002 非一様 affine blur / shadow の検証

作業 worktree は `.worktrees/m3-fx2`、開始 HEAD は `7d02f2b3812fb0af89697fa2d343c97af9695b13`。worker は GPU / hardware codec を持たず、未コミットの差分を supervisor に渡す。GPU / golden は **pending host run**。以下の CPU 検証だけで FX-002 の受け入れ完了とは扱わない。

## 契約

[ADR-0067](../adr/0067-affine-gaussian-effects.md) の effect version **2**、kernel `fx002-affine-ellipse-lattice-rne16-v2`。version **1** と `fx001-separable-gaussian-transparent-rne16-v1` はそのまま維持し、自動移行しない。`C = sigma²(SA)(SA)ᵀ`、`q <= 9` の整数出力 tap、Y / X 順 f32 weights、二次元 convolution 一段、binary16 RNE、透明外部境界。shadow offset は `SA offset`、bilinear source alpha と source-under 合成。semantic support と pixel halo を区別する。

未知版、特異 / 近退化、非有限 covariance、正 sigma の covariance / determinant underflow（直接 determinant は正の normal f64）、radius 1,024 超、探索矩形 65,536 candidates 超は `UNSUPPORTED_FEATURE`。不正 sigma / offset / opacity は既存 render の `RENDER_ERROR`、低層 GPU では `INVALID_INPUT`。既存 surface memory / device limits も適用する。GPU 不在は `ADAPTER_UNAVAILABLE` であり、CPU へ暗黙 fallback しない。

`ResolvedEffect` の `AffineGaussianBlur` / `AffineDropShadow` variant を公開 schema / Swift transport に追加した。保存 `EffectDefinition` の形、Property descriptors、project / API / snapshot schema の構造版は変更しない。`SemanticVersions.effects` は新規 snapshot / capabilities で上限 2、legacy 上限 1 も実行可能。実際の authored effect version を固定したまま algorithm を選ぶ。
