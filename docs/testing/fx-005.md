# FX-005 キーイング（chroma key / luma key）の検証

現在の状態（2026-10-08）: M8 Lane C の作業ブランチ `m8-lane-c` で実装・検証を完了した。検証環境は COLOR-002 / FX-003 と同一の Mac（Apple Silicon + Metal、rustc 1.95.0）。`docs/backlog/backlog.json` の FX-005 更新はこの文書の証拠に基づく。

## 契約

[ADR-0115](../adr/0115-keying-and-standard-effects.md) に従い、versioned effect `version = 1` として次の 2 種を実装した。

- `kronello.keying.chroma` — `key_color`(Color)・`similarity`(0..=1)・`edge_shrink`(design_px)・`edge_feather`(design_px)・`spill`(0..=1)。ストレート色を作業空間の YCbCr 相当へ変換し、Cb/Cr 距離が `similarity * sqrt(2)/2` を超える画素を不透明とする binary マットで alpha を書き換える（`a' = a * m`）。その後 `edge_shrink` の matte erosion と `edge_feather` の Gaussian ぼかしでマットを調整し、`spill` はキー色寄りの彩度を抑制する。
- `kronello.keying.luma` — `key_luma`(0..=1)・`tolerance`(0..=1)・`edge_shrink`・`edge_feather`。ストレート輝度と `key_luma` の距離が `tolerance` 以上なら不透明とする binary マットで alpha を書き換え、同じエッジ調整を適用する。

共通の規約は次の通り。

- すべて premultiplied working space で評価する。keying は alpha を書き換え、RGB は spill 抑制を除き保存する。
- `edge_shrink` / `edge_feather` は非負、`similarity` / `key_luma` / `tolerance` / `spill` は 0..=1 で、`resolve` が型付き `EffectError` で拒否する。非有限値・欠損・型違いも同様に型付き拒否。
- エッジ調整は周辺参照を持つため `required_input` / `halo` を拡張し、DAG の ROI へ反映する。ゼロの場合は pointwise のまま。
- kernel は `fx005006-keying-standard-f16-v1`（RGBA16F・binary16 RNE）。semantic version は `kronello.keying.chroma = 1`、`kronello.keying.luma = 1` として `SemanticVersions::current()` と snapshot に登録する。
- WGSL の追加演算（`config.x == 5` キーイング、`config.x == 6` matte erode）は FXC 互換を意識し、switch・動的ベクトルインデックスを避ける。
- 未知 effect・未知版は従来通り opaque round-trip で、評価は型付き拒否。

## golden シーン

GPU カタログに 7 シーン（FX-006 分を含む）を追加し、**56 シーン・56 comparison frames** に更新した。

- `fx005-chroma-key`: 16×16、左半分がキー緑・右半分が赤の 2 色合成。`similarity=0.4`、`spill=0.5`。
- `fx005-chroma-key-edges`: 同上に `edge_shrink=[1.4,0.6]`・`edge_feather=[0.9,0.4]`・`spill=1.0` を追加し、マット侵食とフェザーの GPU/CPU 一致を検証する。
- `fx005-luma-key`: LinearRec2020 作業空間、暗部/明部の 2 色で `key_luma=0.05`・`tolerance=0.15`・非ゼロ shrink/feather。

3 プラットフォームのカタログ `scene_ids` と `effect_semantic_versions` を更新し、golden harness の `effect_semantic_versions` manifest に 6 効果の版を追加した。固定環境 baseline の UPDATE・採用・通常比較は [golden 比較手順](golden-comparison.md) に従う。
