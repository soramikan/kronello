## Public API / schema

- `MarkerId`（新しい安定 UUID 型）、`Marker`、`MarkerColor`（`red` / `green` / `blue` / `yellow` / `purple` / `cyan` / `orange` / `white` の閉集合）を `kronello-model` に追加。
- `Sequence.markers` / `Clip.markers` / `Sequence.work_area` は `#[serde(default, skip_serializing_if)]` で後方互換。旧文書は default で開け、strict unknown-field 規約を維持する。
- `TimelineCommand` に `marker_set` / `marker_remove` / `marker_move` / `work_area_set` を追加。`sequence.query` の応答は sequence / clip の markers と `work_area` を含む。
- `SequenceRenderRequest.range` の契約は不変。job snapshot（`input.json`）は `work_area` を含む project snapshot と caller 指定 range を別個に固定する。
- `schemas/project-v1.schema.json` / `schemas/api-v1.schema.json` / `GeneratedAPI.swift` を Rust generator から再生成した。schema 番号は 1 を維持。
