## 実行証拠

2026-10-06、macOS 27.0.1 / arm64 の実 stdio + localhost HTTP で script は exit 0。
`sdk-evidence.json` は SDK / OS / revision / protocol / tool names と両 transport の
structured response を保存する。HTTP は localhost の任意 port で起動し、test の外部公開をしない。

SDK の auto probe は server/discover から 2026-07-28 を選び、initialize を使わずに
list_tools / schema resource / project.create / project.info / project.export /
capabilities.get / CPU render.frame / 型付き PROJECT_NOT_FOUND を実行した。
同一の document と rational time の結果は両 transport で完全一致した。
SDK progress callback の受信後に長い render.sequence を cancel し、同じ connection の ping 成功と
確定出力なしを両 transport で確認する。
素材文字列の命令らしい text はそのまま project のデータとして保持した。

Rust の modern tests は要求ごとの metadata / clientCapabilities、未知 version の -32022、
legacy coexistence、HTTP header の missing / mismatch と -32020、Base64 resource name、
未知 method の HTTP 404、session ID を発行しないこと、stream close による queued mutation の
cancellation と active HTTP requests の process limit 32 を検証する。legacy の実 binary stdio tests と protocol lifecycle tests も維持する。
