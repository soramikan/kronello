## 公開 surface と stream

追加 operation は0。scene.query に search / limit / cursor、結果に next_cursor / node tags。
history.list に cursor、結果に next_cursor。EditCommand に node_tags_set {composition,node,tags}。
SceneNode.tags は additive optional set、Project schema version 1。
新 error は INVALID_CURSOR / CURSOR_MISMATCH / CURSOR_EXPIRED。
tag / query の不適合は既存 INVALID_REQUEST / INVALID_EDIT / INVALID_MUTATION family。

通常 CLI は一つの Response JSON + LF。明示 --events ndjson は header version 1、0個以上の progress、
一つの terminal（end / cancelled / error、共有 Response）の UTF-8 / LF stream。
sequence は0から1ずつ増え、各 record flush。stderr は diagnostic のみ。
SIGINT は協調取消で、commit 済み編集・確定済み成果物・detached job を rollback しない。
閉じた stdout には terminal を送れない。OUTPUT_IO_ERROR と非0 exit、取消 flag が契約で、
terminal のない EOF を receiver は不完全と扱う。SIGTERM / SIGKILL、live watch、replay は対象外。
