# GUI-008 Edit 精密編集ツール・マーカー・In/Out の受け入れ記録

状態: モデル層・共有API接続は `m7-lane-d1` 作業ツリーで確認済み（2026-10-07）。実GUIの操作確認（CUA）は親タスク側で実施する残件とする。

## 実装範囲

### 精密編集ツール（slip / slide / roll / ripple delete）

- `TimelineCandidate.Mode` に `slip`・`slide`・`roll` を追加し、既存の「ローカル候補を作り → 幾何だけ更新 → リリース時に一度だけ `edit.plan`/`edit.apply`」の流れに統合した。
- コマンド対応: スリップ `clip_slip`、スライド `clip_slide`、ロール `clip_roll`、削除 `clip_delete`（単数 clip）、隙間を詰める削除 `ripple_delete`（tracks + range）。`delta` は `RationalTime`（frame ÷ fps）の正確な有理数で送る。
- ツール選択は `KRToolStrip` に「スリップ Y・スライド U・ロール N」を追加。ロールは編集点ベースで、クリップ始端を掴んだ場合は直前クリップに付け替える（`beginRollGesture(clip, atStartEdge:)`）。スライド・ロールは共有モデルが要求する隣接クリップの有無を事前に型付きエラー（`INVALID_CLIP`）で表示する。
- 削除の入口: Delete/⌦ で選択クリップを `clip_delete`、⌥Delete と Inspector の「リップル削除」ボタンで `ripple_delete`（対象クリップの `timeline_range` と所属 track を送信）。

### マーカー

- シーケンスマーカーをルーラー上にひし形で表示（`MarkerDiamond`）。クリックで選択＋再生ヘッド移動、ドラッグでリリース時に `marker_move` を1回だけ送信。ダブルクリックまたは `m` キー／ヘッダボタンで `marker_set`、Delete で選択マーカーを `marker_remove`。色変更は `marker_set` の upsert（id 維持）で行い、`MarkerColor` の閉集合 8 色のみを送る。
- クリップマーカーはクリップ内上部に小さなひし形で表示し、`m`+Shift または Inspector ボタンでクリップ範囲内にクランプして追加する。時刻は共有モデル通り sequence 時刻。
- マーカー選択はクリップ選択とは独立し、外部編集で消えた場合は選択を解除する。

### In/Out 作業範囲

- `i` / `o` キーまたはヘッダの In/Out ボタンで `work_area_set` を送信（Out は排他端で playhead+1）。`x`+⌥ または解除ボタンで `work_area: null` を送る。In ≥ Out は型付きエラーで拒否。
- ルーラー上に範囲のハイライト帯、トラック全体に In/Out の境界線を表示。
- Export ページは対象が work_area を持つ Sequence のとき、範囲を「イン〜アウト」にし `startFrame`/`endFrame` を work_area で初期化する（`ExportPageModel.applyWorkAreaDefault`）。

### スナップ

- `snappedFrame` を拡張し、move / trim / marker ドラッグ / ルーラーシーク（再生ヘッド）の全操作で、他クリップ端・再生ヘッド・マーカー・work_area 境界に ±2 フレームで吸着する。編集中のクリップ自身の端は除外する。

## 残件・環境由来の失敗

- 全テスト実行では 84 件中 5 件が失敗したが、すべて `target/fixtures/external/NotoSansCJKjp-Regular.otf` がこの worktree に存在しないことによる `FONT_MISSING` / demo fixture 生成失敗であり、本変更とは無関係の環境由来（`ControlDraftTests`、`testProjectInventoryAndMissing`、`QAEditorTests` 2件、`testNativeTemplateAndExportInspection`）。
- 実 GUI（CUA）で確認すべき残件: ツールストリップの選択とクリップ上のドラッグで各モードが意図通り始まること、ルーラーマーカーのドラッグ・ダブルクリック追加・Delete 削除、In/Out ハイライトの表示、スナップの体感、Edit→Export での既定範囲反映。
- クリップマーカーは表示のみ（Inspector で選択・色変更・削除は可能）。マーカーのコメント編集 UI は未実装（`marker_set` upsert で対応可能）。
- ロール中の編集点移動はレーン上の縦線と delta ラベルで表示。スリップ中のクリップ内オフセット可視化（ソース窓の見え）は簡易な delta ラベルのみ。
