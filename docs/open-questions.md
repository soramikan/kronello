## 保存・同時編集

### OQ-03 レンダージョブの実行主体

常駐デーモンを置かない構成（[ADR-0014](adr/0014-native-gui-in-process-ffi.md)、[ADR-0017](adr/0017-multi-process-optimistic-concurrency.md)）のため、「CLI や MCP 接続が終了しても続くジョブ」を誰が実行するかが未定。
候補: 切り離して起動する `koma worker` プロセス / GUI プロセスが引き受ける / OS のサービス機構。ジョブ記録の置き場所（`.koma` 内か、ユーザーごとの状態 DB か）も合わせて決める。
決定時期: JOB-001。

### OQ-04 複数プロセス編集時の Undo の意味

GUI の Undo が、その後に別プロセス（エージェント）が加えた変更とどう相互作用するか。
候補: Undo を「自分の操作の逆操作を新しいコマンドとして発行」とし、対象が以後に変更されていれば競合として拒否する / 全体で 1 本の履歴を巻き戻す。
決定時期: STORE-001（逆操作情報の保存形式に影響）。

### OQ-05 WAL と単一ファイル性

SQLite を WAL モードで開くと、開いている間は `-wal` / `-shm` の付随ファイルができる。クラウド同期フォルダやネットワークファイルシステム上での安全性、閉じるときの checkpoint 方針、開いたままコピーされた場合の扱いを決める。
決定時期: STORE-001。

### OQ-06 素材参照の再リンクと受け渡し形式

素材は外部参照 + content hash とした。相対パス / 絶対パスの保持方針、移動された素材の再リンク手順、素材同梱アーカイブの形式（zip の展開上限を含む）が未定。
決定時期: MEDIA-001。

### OQ-07 JSON スナップショット / 交換形式のスキーマ

JSON は不変スナップショットまたはインポート形式と位置づけたが、スキーマ本体は未定義。
決定時期: STORE-001。
